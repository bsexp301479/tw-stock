# 台股資金流 tw-stock

收集上市、上櫃個股的行情、本益比、三大法人、月營收、處置／注意股、除權息／減資／面額變更事件，上市、上櫃三大法人買賣金額，加權與櫃買指數、產業鏈族群、台指期日 K 與期貨三大法人未平倉，寫入 SQL Server，再匯出成靜態 JSON 給網站使用。
網站是純前端（`site/`），不需要後端伺服器，日後可直接部署到 Cloudflare Pages 等靜態主機。

```
資料來源 API ──► twstock collect ──► SQL Server ──► twstock export ──► site/data/*.json ──► 瀏覽器
```

## 專案結構

| 路徑 | 說明 |
|---|---|
| `twstock/fetch.py` | HTTP 請求：每個主機各自節流、被封鎖時退避重試 |
| `twstock/collectors/` | `daily` 行情／本益比／法人／加權與櫃買指數、上市、上櫃三大法人買賣金額、ETF 行情、融資融券、借券賣出、官方漲跌家數、`holdings` 主動型 ETF 持股（統一、群益投信）、`alerts` 處置／注意股、`events` 除權息／減資／面額變更事件（還原價格用）、`revenue` 月營收、`financials` 季報（綜合損益表彙總）、`industry` 產業別與發行股數、`chains` 產業鏈族群、`futures` 期貨日 K 與法人未平倉、`history` 補抓歷史、`catchup` 缺什麼補什麼 |
| `twstock/tradingcal.py` | 交易日曆（官方休市表、手寫表、臨時休市） |
| `twstock/health.py` | 資料完整性判斷、`check`、執行紀錄、通知 |
| `twstock/export.py` | 匯出 `site/data/latest.json`、`screen.json`（條件選股與排行擴充用）、`stocks/{代號}.json`、`etfs/{代號}.json`、`etfp/{代號}.json`（第 15 輪 ETF 個股頁） |
| `twstock/analysis/` | `flow` 資金流象限、`forecast` 依期貨法人未平倉的大盤漲跌預測、`chanlun` 纏論 |
| `site/` | 網站：今日（含加權與櫃買指數、台指期日 K、期貨法人未平倉、籌碼因子觀察、信用交易、市場寬度）、泡泡圖、排行（含條件選股、融資融券排行、借券排行）、ETF（含主動型 ETF 持股頁、主動 ETF 彙總）、自選、個股頁（含主動 ETF 持有、融資融券與借券賣出圖、借券指標卡、季報卡）。今日頁指數卡下方分「總覽／法人資金／信用估值／期貨」四頁，個股頁頁首下方分「走勢／籌碼／基本面」三頁，瀏覽器會記住上次選的分頁；個股「基本面」的月營收可切換「今年 vs 去年」（逐月對照去年同月與同期累計）和「近 36 個月」。第 13 輪：表格第一欄（名稱）固定，排行、選股、ETF 表的排序欄放在名稱後的第 2 欄，手機不用橫向捲動；較長的口徑說明預設收合，點「說明」展開（防誤讀的句子保持可見）；個股頁頁首列出當天開、高、低、昨收、量，「走勢」分頁只留 52 週高低、市值、週轉率四張卡；首頁「錢流去哪」預設各顯示 5 個產業，可按「顯示全部」。第 14 輪：營收年增排行只列欄名月份與更新的月份（表下列出未列入的檔數），去年同月營收不到 1,000 萬元的標「基期低」；單季 EPS 年增在去年同季 EPS 大於 0、小於 0.1 元時改顯示「基期低（去年同季 X 元）」；期貨卡加期現貨價差、下次結算日、換月標示與價差迷你圖；殖利率一年位置加方向說明；季報進度附申報截止日。第 15 輪：個股季報卡的累計 EPS 年增套用和單季相同的基期規則（去年同期 > 0 且 < 0.1 元顯示「基期低（去年同期 X 元）」，去年同期 ≤ 0 且本期 > 0 顯示「轉盈」）；ETF 可從搜尋、ETF 列表、`#/stock/{ETF 代號}` 進入 ETF 個股頁（原始價 K 線、量、融資融券與借券；見下方 ETF 一段）；期貨卡價差迷你圖的 0 軸加深；季報截止日加星期與週末順延。第 16 輪：今日頁「總覽」最下方加處置／注意股清單（即將處置、處置中、今日注意三組；`latest.json` 的 `alerts`：`d` = [代號, 起日, 迄日, 措施, 原因]、`n` = [代號, 原因]，原因只取第一句、最多 60 字，完整原因在個股頁），注意組預設 10 檔可按「注意顯示全部」；同一檔多段處置重疊時，`dsp` 與清單合併為 [最早起日, 最晚迄日]。第 17 輪：清單加「接近處置（推算）」組（`latest.json` 的 `alerts.w` = [代號, 1 已達條件／0 差一次, 條件文字]），依注意原因的「第 N 款」推算：第一款（6 日累積漲跌幅）連 3 個交易日，或第 1～8 款連 5 日、10 個交易日內 6 次、30 個交易日內 12 次為「已達條件」，再 1 次即達為「差一次」；處置中、即將處置的股票不列；原因解析不到款別的那筆不計入。注意紀錄起點（上市 2026-10-12、上櫃 10-28）之前不足的天數不補，只會少算。只是推算，是否處置以官方公告為準；`export.COUNT_DOWN` = False 時第一款的跌幅不計入「第一款連續」。選股不提供此條件 |
| `tests/` | 純邏輯測試（不連網、不連資料庫）：`python3 tests/test_iter01.py`、`python3 tests/test_iter02.py`、`python3 tests/test_iter03.py`、`python3 tests/test_iter04.py`、`python3 tests/test_iter05.py`、`python3 tests/test_iter06.py`、`python3 tests/test_iter07.py`、`python3 tests/test_iter08.py`、`python3 tests/test_iter09.py`、`python3 tests/test_iter10.py` |

## 安裝

需要 Python 3.10 以上、Docker、Microsoft ODBC Driver 18 for SQL Server。

1. 複製 `.env.example` 為 `.env`，填入 `DB_PASSWORD`（至少 8 碼，含大小寫英文、數字、符號）。
2. 啟動資料庫（已有自建的 SQL Server 容器就略過）：
   ```bash
   docker compose up -d
   ```
   Windows 或 Intel Mac 請先在 `.env` 加上 `MSSQL_IMAGE=mcr.microsoft.com/mssql/server:2022-latest`。
3. 執行安裝腳本，建立 `.venv`、安裝套件並建立資料表：
   - Mac：`bash scripts/mac/setup.sh`
   - Windows：雙擊 `scripts\windows\setup.bat`

更新程式後若有新增資料表（例如第 1 輪的 `market_index`、`stock_alerts`，第 2 輪的 `price_events`、`insti_amount`，第 3 輪的 `collect_runs`、`market_holidays`，第 4 輪的 `etfs`、`etf_daily`、`margin_trades`、`etf_margin`、`margin_market`，第 5 輪的 `etf_holdings`、`etf_holding_summary`、`market_breadth`，第 6 輪的 `etf_holding_gaps`，第 10 輪的 `quarterly_financials`，第 11 輪的 `sbl_trades`、`etf_sbl` 與 `stocks.shares` 欄），請再執行一次 `python -m twstock setup-db`（可重複執行，不影響既有資料），否則 `collect`、`check`、`export` 會失敗。第 9 輪：`insti_amount` 加 `market` 欄（既有列為 `TWSE`），唯一鍵改成 `(trade_date, market, unit)`；`setup-db` 可重複執行，改表前請先 `backup`，改表後不可再執行舊版程式。

## 日常使用

指令在 Mac 用 `.venv/bin/python`，在 Windows 用 `.venv\Scripts\python`：

```bash
python -m twstock collect --catch-up             # 補齊最近 10 個交易日缺的資料（可重複執行；齊全時 0 個請求、不匯出；季報窗口內每天抓一次季報）。排程用這個
python -m twstock collect --catch-up --days 20   # 回溯 20 個交易日（上限 30，更早用 history）
python -m twstock collect                        # 今天全部重抓覆寫（含指數、台指期、處置／注意股、除權息事件、三大法人金額（上市、上櫃））並匯出網站 JSON
python -m twstock collect --date 2026-10-28      # 指定日期全部重抓覆寫；也用來復原被誤判的臨時休市
python -m twstock check                          # 檢查近 20 個交易日各資料集的完整性（唯讀、不連外）；開頭列最後一次收集與排程狀態；有異常時印建議指令並回傳 1（--days 至少 1）
python -m twstock history --start 2026-01-02     # 補抓歷史（行情、本益比、法人、ETF、融資融券），只補缺的，可中斷重跑
python -m twstock history --start 2025-10-30 --only etf margin   # 只補 ETF 行情與融資融券（同一天 ETF 先於融資融券；一年約 976 個請求、40 分鐘）
python -m twstock history --start 2025-10-30 --only holdings   # 只補主動型 ETF 持股（統一、群益投信 8 檔；上市日之前自動略過；一年約 1,250 個請求、1～2 小時：群益偶爾逾時重試，第 7 輪實測群益 596 次花 52 分鐘）
python -m twstock history --start 2026-01-02 --only insti   # 只補法人
python -m twstock history --start 2025-10-30 --only pe      # 只補本益比／淨值比／殖利率（--only prices 不再順帶寫入）
python -m twstock history --start 2026-02-23 --only index   # 只補加權指數歷史（一天一個請求）
python -m twstock history --start 2025-10-30 --only tpex_index  # 只補櫃買指數（一個月一個請求）
python -m twstock history --start 2026-07-31 --only amount  # 只補三大法人買賣金額（上市、上櫃；已有的市場自動略過；每市場一天一個請求）
python -m twstock history --start 2024-01-01 --only financials   # 只補季報（季底日在範圍內、窗口已開始的季別；每季上市、上櫃各 1 個請求；已有的季別自動略過，--force 重抓；約 22 次、2 分鐘）
python -m twstock history --start 2025-10-30 --only sbl   # 只補借券賣出（上市、上櫃各 1 個請求／天；晚上 8 點半後才有當天資料；一年約 490 次、30 分鐘）；不指定 --only 時不補借券
python -m twstock events --start 2025-10-30      # 補抓除權息／減資／面額變更事件（約 1 分鐘，可重跑）
python -m twstock revenue --year 2026 --month 9 --force     # 重抓某月營收
python -m twstock futures --start 2020-01-01     # 補抓台指期日 K 與期貨三大法人未平倉（--commodity MTX 可抓小台）
python -m twstock chains                         # 立即更新產業鏈族群（collect 每 30 天會自動更新）
python -m twstock export                         # 只重新匯出網站 JSON（含選股用的 screen.json）；history、export 連不上資料庫時印一行說明並回傳 2
python -m twstock serve                          # 本機預覽 http://localhost:8000
python -m twstock chanlun 2330                   # 產生 output/chanlun_2330.svg
python -m twstock backup                         # 備份資料庫到專案上一層的 _backups/（COPY_ONLY＋RESTORE VERIFYONLY；只新增不覆寫；--out 指定資料夾）
python -m twstock setup-db                       # 建立／補建資料表
python3 tests/test_iter01.py                     # 執行測試
python3 tests/test_iter02.py                     # 第 2 輪測試
python3 tests/test_iter03.py                     # 第 3 輪測試
python3 tests/test_iter04.py                     # 第 4 輪測試
python3 tests/test_iter05.py                     # 第 5 輪測試
python3 tests/test_iter06.py                     # 第 6 輪測試
python3 tests/test_iter07.py                     # 第 7 輪測試
python3 tests/test_iter08.py                     # 第 8 輪測試
python3 tests/test_iter09.py                     # 第 9 輪測試
python3 tests/test_iter10.py                     # 第 10 輪測試
```

也可以直接雙擊：Mac 的 `scripts/mac/preview.command`、`collect.command`，Windows 的 `scripts\windows\preview.bat`、`collect.bat`。`collect.command`、`collect.bat` 補齊最近缺的資料（等同 `collect --catch-up`）；帶參數時照傳。

### 自動排程（週一至週五 17:30、19:30、21:45、22:30）

**以下步驟由使用者自行執行**，程式不會自動安裝。排程執行 `collect --catch-up`：缺什麼補什麼，一天多次也不會重抓。22:30 負責當天的異常判定（融資融券等晚間資料 22:00 前未公布才算異常）。

- Mac：`bash scripts/mac/install_schedule.sh`（只看內容不安裝：`--print`；移除：`--uninstall`；其他參數只印用法，不會安裝）。**安裝當下會立刻執行一次**，之後每次登入也會補跑一次。排程以 `caffeinate -i` 執行，只在執行期間防止睡眠，不改系統設定。有異常時發本機通知，同一天同一問題只通知一次。
- Windows：執行 `scripts\windows\install_schedule.bat`（移除：加上 `/uninstall`；其他參數只印用法，不會安裝）。會建立四個工作；要補跑錯過的排程，請在工作排程器勾選各工作的「錯過排程時儘快執行」。異常只寫紀錄。

執行紀錄寫入 `logs/collect.log` 與資料表 `collect_runs`。

**電腦設定（由使用者決定、自行執行）：**

- Mac 睡眠：電腦睡著時排程不會執行，喚醒後合併補跑一次，所以資料通常是「下次打開電腦時補齊」，不會遺失（處置／注意股例外，只查得到近幾日）。要當天晚上就有資料，可固定喚醒（需要管理者權限）：`sudo pmset repeat wakeorpoweron MTWRF 17:25:00`。
- 資料庫容器：重開機後容器沒啟動時收集會失敗（回傳 2、提示啟動）。可設定自動重啟：`docker update --restart unless-stopped MySqlServer`，並在 Docker Desktop 設定開機啟動。

## 備份與還原

資料庫在容器裡，`docker rm` 會一起刪掉。處置／注意股歷史、主動 ETF 持股都無法完整重抓，請定期備份。

```bash
python -m twstock backup                    # 存到專案上一層的 _backups/TwStock_YYYYMMDD_HHMMSS.bak
python -m twstock backup --out ~/Desktop    # 指定資料夾
python -m twstock backup --direct --out D:\backups   # SQL Server 不在 Docker 裡（例如 Windows 本機安裝）：由 SQL Server 直接寫到該資料夾
```

- 使用 `COPY_ONLY`（不影響其他備份），備份後以 `RESTORE VERIFYONLY` 驗證（只驗證、不還原）；檔名含日期時間，只新增、不覆寫，舊備份不會自動刪除，請自行整理（每份約 80 MB）。
- 容器：自動找發布 `DB_SERVER` 埠號的容器（`MySqlServer`、`twstock-mssql` 都適用）；找到多個或名稱特殊時在 `.env` 設定 `DB_CONTAINER=容器名稱`。
- 建議時機：更新程式或補抓歷史之前、每週一次。要定期自動備份，可自行把這個指令加進排程。
- 回傳碼：0 = 成功；1 = 檔名已存在、Docker 問題或備份檔驗證失敗；2 = 連不上資料庫或備份失敗。中途失敗時會刪除容器內這次產生的暫存檔，刪不掉時印出要自行執行的指令。

**還原（沒有提供指令，請手動執行；會覆蓋現有資料，請先停用排程並確認備份檔正確）**：

1. `docker cp _backups/TwStock_….bak MySqlServer:/var/opt/mssql/data/restore.bak`
2. 用 SQL 工具連到 `master` 執行 `RESTORE DATABASE [TwStock] FROM DISK = N'/var/opt/mssql/data/restore.bak' WITH REPLACE`
3. 執行 `python -m twstock check` 確認資料

## 注意事項

- 法人資料通常比收盤行情晚公布，網站上的「法人資料」日期可能比「資料日」早一天。資金流與象限都以法人資料日為準。各資料集獨立收集：行情公布、法人還沒公布時，會先寫入行情並更新網站（不再全有全無），下次排程補上法人。
- 抓取間隔已依各主機設定（證交所 3.5 秒、櫃買 3 秒），請勿調短，否則容易被暫時封鎖。
- `.env` 含資料庫密碼，已列在 `.gitignore`，請勿提交。
- 族群有三種：**類股**（證交所／櫃買產業別）、**產業鏈**（[櫃買中心產業價值鏈平台](https://ic.tpex.org.tw/)，自動更新）、**概念股**（`data/concepts.csv` 手動維護）。
- 台指期日 K 來自期交所「每日行情下載」，以「當天有成交的最近月份」接成近月連續線，只畫日盤。夜盤的日期是成交量歸屬日：標示 10/29 的夜盤是 10/28 15:00 到 10/29 05:00。今日頁的夜盤若在日盤收盤之前（歸屬日 ≤ 日盤日期），標示「前一夜盤」並排在前面；之後的標示「最新夜盤」。

- 市場寬度：今日頁成交額卡的漲跌家數改用**官方**（股票）：上市取自與行情同一個 `MI_INDEX` 回應的「漲跌證券數合計」（不增加請求）、上櫃取自櫃買 `afterTrading/highlight`（每日 +1 請求），2026-11-03 起，歷史不補；沒有官方家數時退回網站自算並註明。**官方與網站自算的差別**：上市官方「股票」欄不含 TDR、另列「無比價」，網站自算把 TDR 算成股票、無比價依參考價算漲跌，2026-11-03 網站自算多 3 漲 3 跌（上櫃一致）。市場寬度卡為自算（股票，不含 ETF，還原收盤）：站上 MA20／MA60 = 收盤 > 含當天的 20／60 日均價的比例，分母 = 當天有收盤且有 20／60 個以上收盤的股票；20 日新高／新低 = 收盤高於／低於前 20 個收盤；量能 = 當天成交額 ÷ 前 20 個交易日平均。
- 資料完整性：每個資料集分市場判斷。**齊全** = 筆數 ≥ max(下限, 近 20 日中位數 × 80%)，且本益比、淨值比、殖利率的非空比例都 ≥ 50%。狀態：**正常**；**尚未公布**（當天 22:00 前還沒有）；**異常**（22:00 後或隔日仍缺、抓取失敗、欄位不符）；**休市**（不列入）。`collect --catch-up` 回傳 0 = 正常、尚未公布、休市或另一個程序正在執行；1 = 有異常；2 = 連不上資料庫（`history`、`export` 等指令連不上資料庫或資料表不存在時也印一行說明並回傳 2，不印 Traceback）。第 4 輪新增上市／上櫃 ETF、上市／上櫃融資融券 4 個資料集。第 5 輪新增上市／上櫃漲跌家數（2026-11-03 起）與 4 檔主動 ETF 持股 6 個資料集；持股在 ETF 上市日之前不算缺；跨境 ETF（00411A、00988A）的持股日晚一個交易日，公布日 22:00 後仍沒有才算異常。`check` 開頭列最後一次收集（時間、指令、有無新資料）與排程狀態（只看 `~/Library/LaunchAgents/com.twstock.collect.plist` 是否存在，不呼叫 `launchctl`；非 Mac 顯示「無法判斷」）；同一交易日所有資料集都缺時合併成一行；有異常時最後印建議指令（缺口 10 天內 `collect --catch-up`、30 天內加 `--days N`、更早用 `history --start`）。網站橫幅在「可能尚未收集」後提示「請在收集資料的電腦執行 python3 -m twstock collect --catch-up」。第 6 輪：主動 ETF 持股遇到投信確定沒有明細的日期（見「主動型 ETF 持股」），算齊全，涵蓋數含這些日期，`check` 另列「投信沒有持股明細（不算缺）」。第 9 輪：新增「上櫃法人金額」一列（2026-07-31 以前不判缺；上市「法人金額」一列只計上市）；「處置／注意股最後成功」之後加「月營收」一行：該月家數 ≥ 前一月 × 98% 為 ✅ 已齊；未達且今天是 1～10 日為 ⏳ 公布期間；已過 10 日但最後一次收集營收是今天或前一個交易日為 ⏳ 晚交公司陸續補進；其餘為 ❌（計入異常，建議執行 `collect --catch-up`）。第 10 輪：月營收一行之後加「季報」一行（例如「第 3 季財報 2026Q3：已收 404 家（前一季 1,984 家的 20%），金融業 3／38 家，⏳ 公布期間（一般業 11/14、金融業 11/29 截止）」；窗口內顯示該季，窗口外顯示最近一個窗口的季別）：收齊條件成立為 ✅ 已齊；窗口外未齊為 ℹ️ 收集期間已結束（**不計異常、不影響回傳碼**）；今天 ≤ 一般業截止後第一個交易日，或總家數已達 98% 且今天 ≤ 金融業截止後第一個交易日為 ⏳ 公布期間；最後一次收集季報是今天或前一個交易日為 ⏳ 晚交公司陸續補進；其餘為 ❌（計入異常，建議執行 `collect --catch-up`）。第 11 輪：新增上市／上櫃借券 2 個資料集（下限上市 800、上櫃 550 檔）。
- 交易日曆：優先用證交所官方休市表（`market_holidays`，只有當年，30 天更新一次），抓不到時只印警告、不影響當次收集，沿用已存的官方表；沒有該年資料時用程式內的手寫表；都沒有時平日一律視為交易日並印警告，**每年年底請確認新年度的休市表**。
- 臨時休市（颱風假）：日期已過，且上市、上櫃、期交所都沒有資料、查詢都沒有失敗時，自動登記為臨時休市，不再算缺漏。判定錯誤時執行 `python -m twstock collect --date 該日`，查到資料就會移除判定。
- 網站的「更新於」是**最後一次收集到新資料的時間**，不是匯出時間；還沒有執行紀錄時退回資料寫入時間，並標示「（依資料寫入時間）」。`history` 補抓不算。依交易日曆資料落後時（交易日 18:00 前看前一交易日，之後看當天，台灣時間），顯示橘色提示；部分資料異常時顯示局部提示。分頁回到前景時會重新檢查，有新資料會提示重新整理，不會自動跳轉。
- 補抓舊日期（`collect --date`、`history`）不會覆蓋股票的名稱與市場別；只有最新日期的資料會更新。
- `_archive/` 是舊腳本，**不要再執行**：它連同一個資料庫，會把上櫃殖利率覆寫成 NULL，並蓋掉名稱與市場別。目前已把 `_archive/config.py` 改名為 `config.py.disabled` 使它無法執行，請不要改回來。
