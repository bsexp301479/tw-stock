# 台股資金流 tw-stock

收集上市、上櫃個股的行情、本益比、三大法人、月營收、處置／注意股、除權息／減資／面額變更事件，上市、上櫃三大法人買賣金額，加權與櫃買指數、產業鏈族群、台指期日 K 與期貨三大法人未平倉，寫入 SQL Server，再匯出成靜態 JSON 給網站使用。
網站是純前端（`site/`），不需要後端伺服器，日後可直接部署到 Cloudflare Pages 等靜態主機。

```
資料來源 API ──► twstock collect ──► SQL Server ──► twstock export ──► site/data/*.json ──► 瀏覽器
```

## 安裝

需要 Python 3.10 以上、Docker、Microsoft ODBC Driver 18 for SQL Server。

1. 複製 `.env.example` 為 `.env`，填入 `DB_PASSWORD`（至少 8 碼，含大小寫英文、數字、符號）。
2. 啟動資料庫（已有自建的 SQL Server 容器就略過）：
   ```bash
   docker compose up -d
   ```
   Windows 或 Intel Mac 請先在 `.env` 加上 `MSSQL_IMAGE=mcr.microsoft.com/mssql/server:2022-latest`。
3. 執行安裝腳本，建立 `.venv`、安裝套件並建立資料表：
   - Mac：`bash scripts/mac/setup.sh`
   - Windows：雙擊 `scripts\windows\setup.bat`

更新程式後若有新增資料表（例如第 1 輪的 `market_index`、`stock_alerts`，第 2 輪的 `price_events`、`insti_amount`，第 3 輪的 `collect_runs`、`market_holidays`，第 4 輪的 `etfs`、`etf_daily`、`margin_trades`、`etf_margin`、`margin_market`，第 5 輪的 `etf_holdings`、`etf_holding_summary`、`market_breadth`，第 6 輪的 `etf_holding_gaps`），請再執行一次 `python -m twstock setup-db`（可重複執行，不影響既有資料），否則 `collect`、`check`、`export` 會失敗。第 9 輪：`insti_amount` 加 `market` 欄（既有列為 `TWSE`），唯一鍵改成 `(trade_date, market, unit)`；`setup-db` 可重複執行，改表前請先 `backup`，改表後不可再執行舊版程式。

## 日常使用

指令在 Mac 用 `.venv/bin/python`，在 Windows 用 `.venv\Scripts\python`：

```bash
python -m twstock collect --catch-up             # 補齊最近 10 個交易日缺的資料（可重複執行；齊全時 0 個請求、不匯出）。排程用這個
python -m twstock collect --catch-up --days 20   # 回溯 20 個交易日（上限 30，更早用 history）
python -m twstock collect                        # 今天全部重抓覆寫（含指數、台指期、處置／注意股、除權息事件、三大法人金額（上市、上櫃））並匯出網站 JSON
python -m twstock collect --date 2026-10-28      # 指定日期全部重抓覆寫；也用來復原被誤判的臨時休市
python -m twstock check                          # 檢查近 20 個交易日各資料集的完整性（唯讀、不連外）；開頭列最後一次收集與排程狀態；有異常時印建議指令並回傳 1（--days 至少 1）
python -m twstock history --start 2026-01-02     # 補抓歷史（行情、本益比、法人、ETF、融資融券），只補缺的，可中斷重跑
python -m twstock history --start 2025-10-30 --only etf margin   # 只補 ETF 行情與融資融券（同一天 ETF 先於融資融券；一年約 976 個請求、40 分鐘）
python -m twstock history --start 2025-10-30 --only holdings   # 只補主動型 ETF 持股（統一、群益投信 8 檔；上市日之前自動略過；一年約 1,250 個請求、1～2 小時：群益偶爾逾時重試，第 7 輪實測群益 596 次花 52 分鐘）
python -m twstock history --start 2026-01-02 --only insti   # 只補法人
python -m twstock history --start 2025-10-30 --only pe      # 只補本益比／淨值比／殖利率（--only prices 不再順帶寫入）
python -m twstock history --start 2026-02-23 --only index   # 只補加權指數歷史（一天一個請求）
python -m twstock history --start 2025-10-30 --only tpex_index  # 只補櫃買指數（一個月一個請求）
python -m twstock history --start 2026-07-31 --only amount  # 只補三大法人買賣金額（上市、上櫃；已有的市場自動略過；每市場一天一個請求）
python -m twstock events --start 2025-10-30      # 補抓除權息／減資／面額變更事件（約 1 分鐘，可重跑）
python -m twstock revenue --year 2026 --month 9 --force     # 重抓某月營收
python -m twstock futures --start 2020-01-01     # 補抓台指期日 K 與期貨三大法人未平倉（--commodity MTX 可抓小台）
python -m twstock chains                         # 立即更新產業鏈族群（collect 每 30 天會自動更新）
python -m twstock export                         # 只重新匯出網站 JSON（含選股用的 screen.json）；history、export 連不上資料庫時印一行說明並回傳 2
python -m twstock serve                          # 本機預覽 http://localhost:8000
python -m twstock chanlun 2330                   # 產生 output/chanlun_2330.svg
python -m twstock backup                         # 備份資料庫到專案上一層的 _backups/（COPY_ONLY＋RESTORE VERIFYONLY；只新增不覆寫；--out 指定資料夾）
python -m twstock setup-db                       # 建立／補建資料表
python3 tests/test_iter01.py                     # 執行測試
python3 tests/test_iter02.py                     # 第 2 輪測試
python3 tests/test_iter03.py                     # 第 3 輪測試
python3 tests/test_iter04.py                     # 第 4 輪測試
python3 tests/test_iter05.py                     # 第 5 輪測試
python3 tests/test_iter06.py                     # 第 6 輪測試
python3 tests/test_iter07.py                     # 第 7 輪測試
python3 tests/test_iter08.py                     # 第 8 輪測試
python3 tests/test_iter09.py                     # 第 9 輪測試
```

也可以直接雙擊：Mac 的 `scripts/mac/preview.command`、`collect.command`，Windows 的 `scripts\windows\preview.bat`、`collect.bat`。`collect.command`、`collect.bat` 補齊最近缺的資料（等同 `collect --catch-up`）；帶參數時照傳。

### 自動排程（週一至週五 17:30、19:30、21:45、22:30）

**以下步驟由使用者自行執行**，程式不會自動安裝。排程執行 `collect --catch-up`：缺什麼補什麼，一天多次也不會重抓。22:30 負責當天的異常判定（融資融券等晚間資料 22:00 前未公布才算異常）。

- Mac：`bash scripts/mac/install_schedule.sh`（只看內容不安裝：`--print`；移除：`--uninstall`；其他參數只印用法，不會安裝）。**安裝當下會立刻執行一次**，之後每次登入也會補跑一次。排程以 `caffeinate -i` 執行，只在執行期間防止睡眠，不改系統設定。有異常時發本機通知，同一天同一問題只通知一次。
- Windows：執行 `scripts\windows\install_schedule.bat`（移除：加上 `/uninstall`；其他參數只印用法，不會安裝）。會建立四個工作；要補跑錯過的排程，請在工作排程器勾選各工作的「錯過排程時儘快執行」。異常只寫紀錄。

執行紀錄寫入 `logs/collect.log` 與資料表 `collect_runs`。

**電腦設定（由使用者決定、自行執行）：**

- Mac 睡眠：電腦睡著時排程不會執行，喚醒後合併補跑一次，所以資料通常是「下次打開電腦時補齊」，不會遺失（處置／注意股例外，只查得到近幾日）。要當天晚上就有資料，可固定喚醒（需要管理者權限）：`sudo pmset repeat wakeorpoweron MTWRF 17:25:00`。
- 資料庫容器：重開機後容器沒啟動時收集會失敗（回傳 2、提示啟動）。可設定自動重啟：`docker update --restart unless-stopped MySqlServer`，並在 Docker Desktop 設定開機啟動。

## 備份與還原

資料庫在容器裡，`docker rm` 會一起刪掉。處置／注意股歷史、主動 ETF 持股都無法完整重抓，請定期備份。

```bash
python -m twstock backup                    # 存到專案上一層的 _backups/TwStock_YYYYMMDD_HHMMSS.bak
python -m twstock backup --out ~/Desktop    # 指定資料夾
python -m twstock backup --direct --out D:\backups   # SQL Server 不在 Docker 裡（例如 Windows 本機安裝）：由 SQL Server 直接寫到該資料夾
```

- 使用 `COPY_ONLY`（不影響其他備份），備份後以 `RESTORE VERIFYONLY` 驗證（只驗證、不還原）；檔名含日期時間，只新增、不覆寫，舊備份不會自動刪除，請自行整理（每份約 80 MB）。
- 容器：自動找發布 `DB_SERVER` 埠號的容器（`MySqlServer`、`twstock-mssql` 都適用）；找到多個或名稱特殊時在 `.env` 設定 `DB_CONTAINER=容器名稱`。
- 建議時機：更新程式或補抓歷史之前、每週一次。要定期自動備份，可自行把這個指令加進排程。
- 回傳碼：0 = 成功；1 = 檔名已存在、Docker 問題或備份檔驗證失敗；2 = 連不上資料庫或備份失敗。中途失敗時會刪除容器內這次產生的暫存檔，刪不掉時印出要自行執行的指令。

**還原（沒有提供指令，請手動執行；會覆蓋現有資料，請先停用排程並確認備份檔正確）**：

1. `docker cp _backups/TwStock_….bak MySqlServer:/var/opt/mssql/data/restore.bak`
2. 用 SQL 工具連到 `master` 執行 `RESTORE DATABASE [TwStock] FROM DISK = N'/var/opt/mssql/data/restore.bak' WITH REPLACE`
3. 執行 `python -m twstock check` 確認資料

## 注意事項

- 法人資料通常比收盤行情晚公布，網站上的「法人資料」日期可能比「資料日」早一天。資金流與象限都以法人資料日為準。各資料集獨立收集：行情公布、法人還沒公布時，會先寫入行情並更新網站（不再全有全無），下次排程補上法人。
- 抓取間隔已依各主機設定（證交所 3.5 秒、櫃買 3 秒），請勿調短，否則容易被暫時封鎖。
- `.env` 含資料庫密碼，已列在 `.gitignore`，請勿提交。
- 族群有三種：**類股**（證交所／櫃買產業別）、**產業鏈**（[櫃買中心產業價值鏈平台](https://ic.tpex.org.tw/)，自動更新）、**概念股**（`data/concepts.csv` 手動維護）。
- 台指期日 K 來自期交所「每日行情下載」，以「當天有成交的最近月份」接成近月連續線，只畫日盤。夜盤的日期是成交量歸屬日：標示 10/29 的夜盤是 10/28 15:00 到 10/29 05:00。今日頁的夜盤若在日盤收盤之前（歸屬日 ≤ 日盤日期），標示「前一夜盤」並排在前面；之後的標示「最新夜盤」。
- 期貨三大法人未平倉來自期交所「三大法人－區分各期貨契約」，抓大台（TXF）、小台（MXF）、微台（TMF），換算成約當大台 = 大台 + 小台/4 + 微台/20。
- 籌碼因子觀察（大盤漲跌預測）：以外資淨未平倉水位、外資 1 日／5 日增減、投信與自營商 1 日增減（相對近 60 日標準化）做羅吉斯迴歸，預測下一交易日台指期近月日盤漲跌。網站同時顯示 walk-forward 回測命中率與「永遠猜多數方向」的基準；模型沒有勝過基準時，首頁只顯示因子方向，機率與回測收在摺疊區；僅供籌碼面參考，非投資建議。
- 個股法人：排行可切換 1 日／5 日，提供外資、投信、自營、法人合計的買超／賣超與連買排行；金額 = 張數 × 當日收盤（估算值，與官方公布的買賣金額可能不同）。
- 條件選股（排行頁「選股」，`#/rank/screen`）：資料來自 `site/data/screen.json`（匯出時計算，0 個外部請求），在瀏覽器合併 `latest.json` 篩選，只做 AND。條件分流動性、價量、法人、信用、基本面、排除六組，另有 7 組預設（法人連買＋營收創新高、投信認養、帶量突破、多頭排列＋相對強勢、價值高息、營收高成長、籌碼換手）與 2 組參考（融資追價、軋空觀察）。報酬、乖離、均線、新高新低用**還原價格**；量比 = 今日成交額 ÷ 前 20 個交易日平均（無成交日以 0 計），用成交額所以不受面額變更影響；相對大盤 = 個股報酬 − 指數報酬（上市對加權、上櫃對櫃買）。本益比、殖利率、淨值比條件**預設排除 90 天內股本變動**的股票（官方值可能尚未調整），可關閉，關閉後結果列標示「股本變動」。營收以各股最新公布的月份計算，頁面列出各月份檔數；每月 1～10 日是公布期間，各股月份不同，月份混雜時資料日一行加註說明，營收欄標出和欄名不同的月份。第 9 輪新增「淨值比一年位置 ≤ N%」（`screen.json` 的 `pbp`，見估值位置），和其他估值條件一樣預設排除股本變動。「重設」回到預設（保留排除處置股、今日無成交、股本變動與預設排序），不是全部清空。條件存在瀏覽器，網址也會帶條件，可用「複製條件連結」分享。排行另加量比、創新高、20 日相對強勢、營收年增、殖利率、本益比最低（後兩者排除虧損與股本變動）。`screen.json` 不存在時這些功能不出現，既有排行照常。
- 今日頁三大法人卡：上市為證交所 BFI82U 官方買賣金額（含 ETF；外資 = 外資及陸資，不含外資自營商，外資自營商已計入自營商），附近 20 日外資買賣超與連買／連賣天數；上櫃為櫃買 `insti/summary` 官方買賣金額（第 9 輪，2026-07-31 起；`latest.json` 的 `insti_official_tpex`，結構同 `insti_official`），另列一行（合計、外資、投信、自營）與上櫃外資 20 日迷你圖，日期早於網站資料日時標示「尚未更新」；上櫃官方尚無任何資料時才退回張數 × 收盤估算（不含 ETF）。上市、上櫃同一天時可相加，卡片不另列合計。資料表 `insti_amount` 以 `market`（`TWSE`／`TPEx`）區分市場。
- 今日頁估值位置卡（第 9 輪，`latest.json` 的 `valuation`）：上市、上櫃股票的官方本益比、淨值比、殖利率**中位數**在近一年的位置。窗口 = 最近 242 個有官方本益比資料的交易日；中位數每天分市場計算，本益比、淨值比只計入大於 0 的股票，殖利率計入非空值（含 0）；位置 = 窗口內中位數小於或等於今天的天數 ÷ 天數；今天是窗口最低／最高時顯示「一年最低／最高」；附上市本益比中位數近 60 日迷你圖。**不是加權指數本益比**；本益比用近 4 季 EPS，財報公布期間 EPS 變化也會改變位置；殖利率用去年股利；只是位置，不是買賣訊號。
- 個股頁估值位置（第 9 輪，`stocks/{代號}.json` 的 `val`：`{d, pe|pb|dy: [位置 %, 一年最低, 一年最高]}`）：本益比、淨值比、殖利率指標卡加「一年位置 N%（最低～最高）」，窗口同上，只計入大於 0 的官方值（殖利率 0 = 不配息，不算位置）。今天值為空或 ≤ 0（虧損、無股利）、窗口內有效天數少於 120 天（新上市），或 90 天內股本變動（官方值可能尚未調整）時不顯示。本益比位置也反映獲利變化（獲利下降時本益比升高），請一併看淨值比。
- 今日頁法人買超／賣超表與錢流標示「估算，不含 ETF」；三大法人卡的官方值含 ETF 與權證避險，兩者口徑不同。
- 加權指數取自證交所 MI_INDEX（與上市行情同一個請求）；櫃買指數取自櫃買 `indexInfo/inx`（月查詢，可查歷史），缺的月份由 `collect --catch-up` 或 `history --only tpex_index` 補。

- 融資融券：上市取自證交所 `MI_MARGN`（`selectType=ALL`）、上櫃取自櫃買 `margin/balance`，每市場每日 1 個請求；同市場當天行情還沒有時不發請求。當天 22:00 前還沒公布記「尚未公布」，之後才算異常。**今日頁「信用交易」卡的頭條是股票口徑（不含 ETF）**：官方「信用交易統計」含 ETF，只列融資金額一行並註明「官方，含 ETF」；ETF 另列一行「ETF 另計（不計入上方）」。官方融資、融券張數不顯示，因為 ETF 會讓方向失真（例：2026-11-03 官方融券 +63,031 張，其中 00406A 一檔就 +65,270 張，股票本身只 +6,876 張）。增減 = 官方每列的今日餘額 − 前日餘額。
- 融資使用率 = 融資餘額 ÷ 限額（上市用「次一營業日限額」、上櫃用「資限額」），截斷到小數 2 位，限額 0 或空時顯示 `--`；券資比 = 融券餘額 ÷ 融資餘額。上市註記 O 停止融資、X 停止融券、@ 融資分配、% 融券分配、! 停止買賣，表示**次一營業日**的狀況，個股頁加註；上櫃備註存原文、不解讀。個股頁「無信用交易」表示該股不在融資融券清單，與融資 0 張不同。
- 融資融券排行（排行頁）：融資增加／減少（可切換估算金額與張數，預設估算金額 = 張數 × 1,000 × 收盤，**是估算，不是官方融資金額**）、融資增加率、融券增加／減少、券資比、融資使用率，可切換 1 日／5 日。融資增加率的基期（1 或 5 日前餘額）至少 1,000 張；券資比只列融資 1,000 張以上。面額變更、減資時，官方會把融資融券餘額換算成新單位（例：寶雅 5904 2026-08-10 面額 10 元改 1 元，融資 594 張 → 前日餘額 5,940 張）：網站以「事件後第一天的官方前日餘額 ÷ 前一天餘額」為換算係數，5 日增減與個股圖的「還原」都用換算後的值；除權不換算。個股頁 K 線組新增「融資／融券餘額」圖（`stocks/{代號}.json` 的 `mg`：與日線對齊的官方原始餘額，`k` 為換算紀錄），和 K 線同步拖曳，跟著「還原／原始」切換。今日頁信用交易卡加「看排行 →」，並註明維持率的參考值是經驗值、非官方門檻。
- 大盤融資維持率（**自算、非官方**）= Σ(融資張數 × 1,000 × 收盤) ÷ 官方融資金額，分子含股票與 ETF；當日無成交用最近一次收盤；有收盤的融資張數 ÷ 官方融資張數（涵蓋率）不足 99% 時顯示「資料不足」。
- ETF：代號 `00` 開頭、4～6 碼、數字後最多一個英文字尾（例：0050、00878、006201、00406A、00679B）；ETN、受益證券、TDR、權證、特別股不算。ETF 存在獨立的資料表（`etfs`、`etf_daily`、`etf_margin`），`stocks` 表沒有任何 ETF。行情取自與股票同一個 `MI_INDEX`／`dailyQuotes` 回應，**每日不增加請求**；歷史需用 `history --only etf` 補抓。ETF 頁（`#/etf`）列出全部 ETF 的收盤、漲跌、成交量（張）、成交額（億）、融資融券餘額與增減（張），可依成交額、漲幅、跌幅、融資增減、融券增減排序並篩選上市／上櫃。**ETF 不計入**首頁家數與成交額、類股／產業鏈／概念股資金流與泡泡圖、排行、自選、搜尋、個股頁、法人估算、股票口徑的融資融券；只計入大盤融資維持率的分子。上市官方三大法人金額本來就含 ETF。
- 主動型 ETF 持股：取自投信每日申購買回清單，間隔 3 秒：統一投信（`www.ezmoney.com.tw` 的 `GetPCF`）00981A、00403A、00411A、00988A；群益投信（`www.capitalfund.com.tw` 的 `CFWeb/api/etf/buyback`，第 7 輪）00982A、00992A、00415A、00997A。群益的明細只有股數與權重，**沒有市值**（資料庫存 NULL，不推算）。**00406A（中信）與其他投信尚未支援**，ETF 頁標示「持股尚未支援」。日期以**持股日**為準：國內 ETF（00981A、00403A、00982A、00992A、00415A）當天傍晚公布當天的持股；跨境 ETF（00411A、00988A、00997A）晚一個交易日（11/03 晚上公布的是 11/02 的持股）。單位：台股為張（股數 ÷ 1,000）、海外股票為股，海外與期貨只在 ETF 持股頁顯示原文。持股頁（`#/etf/代號`）列淨資產、每單位淨值、股票權重合計、持股檔數、期貨，以及每檔的持有張數、權重、1 日增減、1 日權重變化、5 日增減、「新」與出清；個股頁「主動 ETF 持有」卡列出持有該股的已支援 ETF。這 8 檔都是現金申購買回：申購的資金由經理人買進股票，**申購多的日子加碼會偏多**（例：2026-11-04 00982A 單位數 +2.23%，31 檔加碼中 24 檔的增幅在 1.1%～2.9%），所以張數增減不全是經理人看好或看壞。持股頁摘要、主動 ETF 彙總與今日小卡列出各檔「單位數 1 日」變化（相對前一持股日），可對照。權重變化另含股價漲跌的影響。個股頁「主動 ETF 持有」卡另列「投信買超中已收主動 ETF 的張數」：只計入國內 5 檔、持股日與法人資料日相同的 ETF（含新進與出清），同向且不超過投信合計時顯示百分比；投信買賣超（T86）含所有投信基金與 ETF。新增統一或群益投信的主動 ETF：在 `twstock/health.py` 的 `HOLDINGS` 加一列（代號 → 基金代碼、delay、上市日、投信），再執行 `history --start 上市日 --only holdings`。**海外休市日**（跨境 ETF 當天沒有持股清單，例如美國感恩節）與**臺股臨時休市前一個交易日**（投信只公布彙總、沒有明細）會記在 `etf_holding_gaps`，`check` 視為正常並另列一行，不再請求；持股頁與 1 日增減以前一個有明細的持股日為準。臨時休市前一日的明細在生效日之前都當成尚未公布，所以當晚 22:00 後可能先顯示異常，隔天收集後自動消失。

- 市場寬度：今日頁成交額卡的漲跌家數改用**官方**（股票）：上市取自與行情同一個 `MI_INDEX` 回應的「漲跌證券數合計」（不增加請求）、上櫃取自櫃買 `afterTrading/highlight`（每日 +1 請求），2026-11-03 起，歷史不補；沒有官方家數時退回網站自算並註明。**官方與網站自算的差別**：上市官方「股票」欄不含 TDR、另列「無比價」，網站自算把 TDR 算成股票、無比價依參考價算漲跌，2026-11-03 網站自算多 3 漲 3 跌（上櫃一致）。市場寬度卡為自算（股票，不含 ETF，還原收盤）：站上 MA20／MA60 = 收盤 > 含當天的 20／60 日均價的比例，分母 = 當天有收盤且有 20／60 個以上收盤的股票；20 日新高／新低 = 收盤高於／低於前 20 個收盤；量能 = 當天成交額 ÷ 前 20 個交易日平均。
- 資料完整性：每個資料集分市場判斷。**齊全** = 筆數 ≥ max(下限, 近 20 日中位數 × 80%)，且本益比、淨值比、殖利率的非空比例都 ≥ 50%。狀態：**正常**；**尚未公布**（當天 22:00 前還沒有）；**異常**（22:00 後或隔日仍缺、抓取失敗、欄位不符）；**休市**（不列入）。`collect --catch-up` 回傳 0 = 正常、尚未公布、休市或另一個程序正在執行；1 = 有異常；2 = 連不上資料庫（`history`、`export` 等指令連不上資料庫或資料表不存在時也印一行說明並回傳 2，不印 Traceback）。第 4 輪新增上市／上櫃 ETF、上市／上櫃融資融券 4 個資料集。第 5 輪新增上市／上櫃漲跌家數（2026-11-03 起）與 4 檔主動 ETF 持股 6 個資料集；持股在 ETF 上市日之前不算缺；跨境 ETF（00411A、00988A）的持股日晚一個交易日，公布日 22:00 後仍沒有才算異常。`check` 開頭列最後一次收集（時間、指令、有無新資料）與排程狀態（只看 `~/Library/LaunchAgents/com.twstock.collect.plist` 是否存在，不呼叫 `launchctl`；非 Mac 顯示「無法判斷」）；同一交易日所有資料集都缺時合併成一行；有異常時最後印建議指令（缺口 10 天內 `collect --catch-up`、30 天內加 `--days N`、更早用 `history --start`）。網站橫幅在「可能尚未收集」後提示「請在收集資料的電腦執行 python3 -m twstock collect --catch-up」。第 6 輪：主動 ETF 持股遇到投信確定沒有明細的日期（見「主動型 ETF 持股」），算齊全，涵蓋數含這些日期，`check` 另列「投信沒有持股明細（不算缺）」。第 9 輪：新增「上櫃法人金額」一列（2026-07-31 以前不判缺；上市「法人金額」一列只計上市）；「處置／注意股最後成功」之後加「月營收」一行：該月家數 ≥ 前一月 × 98% 為 ✅ 已齊；未達且今天是 1～10 日為 ⏳ 公布期間；已過 10 日但最後一次收集營收是今天或前一個交易日為 ⏳ 晚交公司陸續補進；其餘為 ❌（計入異常，建議執行 `collect --catch-up`）。
- 交易日曆：優先用證交所官方休市表（`market_holidays`，只有當年，30 天更新一次），抓不到時只印警告、不影響當次收集，沿用已存的官方表；沒有該年資料時用程式內的手寫表；都沒有時平日一律視為交易日並印警告，**每年年底請確認新年度的休市表**。
