## 一、淺色／深色切換

| 項目 | 做法 | 位置 |
|---|---|---|
| 按鈕 | 頂欄最右側一顆圓鈕（34px）。深色時顯示太陽、淺色時顯示月亮，`title`、`aria-label` 寫「切換為淺色／深色」。手機也在頂欄（搜尋框右邊） | `site/index.html` `#themeBtn`；`site/app.css` `.theme-btn` |
| 預設 | 沒選過就跟系統（`prefers-color-scheme`），系統切換時也跟著重畫 | `site/app.js` `setupTheme` |
| 記住選擇 | 按一下在淺色、深色之間切換，存在 `localStorage` 的 `tw.theme`。選過之後就不再跟系統 | `setupTheme` |
| 不閃爍 | `index.html` 在載入 CSS 前用一行 inline script 先套用 `data-theme` | `index.html` `<head>` |
| 圖表 | K 線、泡泡圖等的顏色是畫圖當下從 CSS 取的，所以切換後重畫目前頁面（`route()`），並回到原本的捲動位置 | `redrawKeepScroll` |
| CSS | 第 25 輪已備好 `:root:not([data-theme="light"])`（系統深色）與 `:root[data-theme="dark"]` 兩段，本輪沒有改色值 | `site/app.css` |

- 限制：選過之後無法回到「跟系統」。要恢復時，清掉網站資料或在主控台執行 `localStorage.removeItem('tw.theme')`。

## 二、色調評估

| 項目 | 淺色 | 深色 | 說明 |
|---|---|---|---|
| 漲（`--up`）對卡片底 | 5.14 | 5.34 | 都 ≥ 4.5 |
| 跌（`--dn`）對卡片底 | 5.21 | 7.58 → 5.34 | 都 ≥ 4.5 |
| 跌／漲亮度比 | 0.98 | **1.50 → 1.00** | 原本深色模式的綠比紅亮 1.5 倍，跌的數字與 K 棒比漲更搶眼；已調整（見下） |

- 紅漲綠跌符合台股習慣，淺色模式紅綠亮度平衡。
- `--up-bg`、`--dn-bg`（淺色）仍是第 25 輪調色前的 rgba（`214,69,69`、`48,164,108`），與新的 `--up`、`--dn` 色相略有差距；只是 10% 底色，影響很小。
- **使用者決定調整（已套用）**：深色 `--dn` 改為 `#349f6a`。
  - 這是同色相、只降亮度：與 `--up` 亮度比 1.00，對 `--card` 5.34、`--card2` 4.91、`--bg` 5.77，都和 `--up` 相同。
  - `--on-fill`（#111）在新綠色上是 5.68。
  - 深色的 `--dn-bg`、`--q-ebb` 也換成同一個綠色（透明度不變）。
  - 兩段深色區塊都已修改。
  - `test_iter26` 新增 `test_dark_green_balanced` 鎖住亮度比 0.9～1.1。
  - `app.css?v=56df32ca`。
  - 8001 深色實測：K 線紅綠亮度相近，排行的 `.dn` 取色為 `rgb(52,159,106)`；主控台 0 錯誤。
  - 淺色模式不變。
- 紅綠色弱：數字都有 ＋／− 號，表格不會只靠顏色分辨；K 線只靠顏色，屬看盤軟體慣例。
