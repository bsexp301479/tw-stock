## 五、和既有資料的重複與衝突處理

| 情況 | 建議處理 | 理由 |
|---|---|---|
| 預告日到了、實際事件也進來 | 匯出只取「除權息日 > 資料日」的預告；當天起以 `dv`／`ev`（實際）為準 | 實際表有官方參考價與前收，是本站填息計算的依據 |
| 預告金額和實際不同（公司修正） | 不比對、不覆蓋實際；預告每晚以最新快照為準 | 本次 54／54 吻合，衝突機率低；就算不同，實際的才是官方結果 |
| 預告修改除權息日（延後、取消） | 以（代號, 除權息日）為鍵存；每列記 `first_seen`、`last_seen`；匯出只取 `last_seen` = 最近一次成功抓取日 | 舊日期的列不再出現 → 自動不匯出；保留紀錄方便查「改過幾次」 |
| 某一邊這晚抓失敗 | 該市場的列不更新 `last_seen`；匯出改用「該市場最近一次成功」的日期判斷，不讓整個市場消失 | `isolated=True` 不重試，不影響行情收集（同第 24 輪 F24-7c） |
| ETF 金額「待公告」 | 存 NULL，旗標 `pending`；匯出寫 `c: null` | 前端寫「金額待公告」，工具頁不帶入 |
| 現金增資（現增配股率 > 0） | 存配股率與認購價（文字如「尚未公告」「註4」存 NULL） | 工具頁不處理現增（第 39 輪範圍），只提示 |
| `fund.dy` | 不受影響 | 官方殖利率是年度口徑，預告是單次 |
| 8 位小數 | 存 DECIMAL(16,8)；匯出去掉尾端 0 | 工具頁 `tlBig(st.c, 6)` 只收 6 位，若真出現 7～8 位要決定截斷或放寬（Q40-5） |
| ETN、受益證券、TDR | 不收 | 比照 `is_valid_stock_code`、`is_etf_code` |

## 六、功能拆分

### F40-1 收集（新資料表）

- 新表（暫名 `dividend_notices`，見 D86-1）：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `code` | NVARCHAR(10) | 股票或 ETF 代號 |
| `market` | NVARCHAR(4) | TWSE／TPEx |
| `is_etf` | BIT | |
| `ex_date` | DATE | 除權除息日 |
| `event_type` | NVARCHAR(4) | 息／權／權息 |
| `cash_div` | DECIMAL(16,8) NULL | NULL = 待公告 |
| `stock_ratio` | DECIMAL(16,8) | 每股無償配股率 |
| `sub_ratio`、`sub_price` | DECIMAL(16,8)、DECIMAL(10,2) NULL | 現增配股率、認購價 |
| `first_seen`、`last_seen` | DATE | 第一次、最近一次在預告表看到 |
| 唯一鍵 | (`code`, `ex_date`) | |

- 收集：在 `execute_plan` 的 `events` 之後、同一條件下呼叫（每個新交易日一次），2 次請求、`isolated=True`；MERGE（有就更新金額與 `last_seen`，沒有就新增）。
- 只寫 `stocks`、`etfs` 表已有的代號（同 `collect_events`）。
- 輸出一行：「📅 除權除息預告：上市 N 筆、上櫃 M 筆（11/24 ～ 2027/01/05）」。
- `check`：「除權除息預告最後成功：11/21（上市 N、上櫃 M）」；超過 3 個交易日沒成功要 ⚠️。
- `setup-db` 建表（可重複執行）。
- **回補：做不到**（兩個來源都是當下快照）；套用當晚起才有資料。
- 每晚請求數：**+2**（約 41 → 43）。

### F40-2 匯出

- 個股 `stocks/{代號}.json`、ETF `etfp/{代號}.json` 加 `nx`（沒有就不輸出，舊檔逐位元組不變）：
  - `nx = [{d, t, c, s, sr, sp}]`：除權息日、類型、現金（null = 待公告）、每千股配股（`stock_ratio × 1000`）、現增配股率、認購價；只放「除權息日 > 資料日」且 `last_seen` 有效的列，日期舊到新（通常只有 1 列）。
- 筆數很少（本次 33 檔），檔案大小影響可忽略。
- 是否觸發匯出：預告表抓到和本站「有新資料」同一晚，不另外改判斷（D86-5）。

### F40-3 前端

- `tools.js`：
  - `tlLoad` 的 `ex` 改為 `nx[0].d`（`tlDtOut` 既有提示開始出現）。
  - `tlDvLoad`：有 `nx` 且 `c` 不是 null、沒有現增 → 帶入 `c`、`s`，提示「已帶入 12/03 除息的預告股利（證交所預告表，僅供參考，以公司公告為準）」；`c` 為 null → 照舊帶最近一次，多一句「12/03 除息，金額待公告」；有現增 → 不帶，提示「12/04 除權含現金增資，參考價請看官方公告」。
  - 「上次官方參考價」對照、近一年合計照舊。
- `stock.js`：股票「股利與填息」、ETF「配息與填息」卡標題下加一行（比照 F39-3 用 DOM 插入，`divHTML` 字面不變）：「即將除息 12/03：現金 0.624652 元（預告，以公司公告為準）」。
- 改 js 要同步 `index.html` 的 `?v=`。

### F40-4 今日頁「近期除權息」（選做）

### F40-5 上市權息分項回填（建議待辦）
