### 解析（純函式，可單獨測）

| 規則 | 上市 TWT48U | 上櫃 `tpex_exright_prepost` |
|---|---|---|
| 端點 | `GET https://www.twse.com.tw/rwd/zh/exRight/TWT48U`，`params={"response": "json"}` | `GET https://www.tpex.org.tw/openapi/v1/tpex_exright_prepost`（無參數） |
| 日期 | `除權除息日期`「115年12月03日」→ `roc_date` | `ExRrightsExDividendDate`「1151203」→ `roc_date`（欄名照官方拼法 `ExRrights`） |
| 代號 | `股票代號` | `SecuritiesCompanyCode` |
| 類型 | `除權息`：息／權／權息 | `ExRrightsExDividend`：除息／除權／除權息 → `lstrip("除")` |
| 現金 | `現金股利`；`clean_number` 解析不了（含「待公告實際收益分配金額」HTML、空白）→ NULL | `CashDividend`；「尚未公告」→ NULL |
| 無償配股率 | `無償配股率` | `StockDividendRatio` |
| 現增 | `現金增資配股率`、`現金增資認購價` | `SubscriptionRatioToNewSharesIssued`、`SubscriptionPricePerShare` |

- 只收 `is_valid_stock_code` 或 `is_etf_code` 為真的代號；ETN（020038）、受益證券（01007T）等不收（比照 `parse_events_all`）。
- 日期無法解析、類型不在（息、權、權息）的列略過。
- 同一回應同鍵（代號, 除權息日）重複時只留最後一筆（避免 MERGE 同列更新兩次）。
- **欄位不符**（上市 `stat` 是 OK 但缺必要欄位、上櫃回應不是陣列或第一列缺必要欄位）→ `SchemaError`。
- **沒有資料**（上市 `stat` 不是 OK 且沒有 `fields`／`data`、上櫃空陣列）→ 0 筆，算成功。
- 無償配股率、現增配股率解析不了 → 0；現金與認購價解析不了 → NULL（只有這兩欄允許 NULL）。

## 二之二、F40-2 匯出 `nx`

### 選列規則

1. 每個市場的「有效快照日」= `state["notices"][市場]` 的日期（最近一次成功抓取日）；該市場從沒成功 → 該市場沒有 `nx`。
2. 只取 `last_seen` = 該市場有效快照日、且 `ex_date` > 資料日（`latest_date`，兩市場的最新行情日）的列。
   - 某市場這晚失敗：有效快照日停在上次成功日，上次快照的列照樣匯出（D86-6「沿用」）。
   - 預告改日期：舊日期那列的 `last_seen` 停在舊日，不再匯出；新日期那列匯出。
   - 成功但 0 筆：該市場沒有任何列匯出。
   - 到了除權息日（資料日 ≥ `ex_date`）就不匯出，改看 `dv`／`ev`（實際事件為準）。
3. 股票（`is_etf` = 0）寫進 `stocks/{代號}.json`；ETF（`is_etf` = 1）寫進 `etfp/{代號}.json`。該檔本來不匯出（例：ETF 不在 `etf_latest`）就不匯出。

### 欄位格式

```json
"nx": [{"d": "2026-12-03", "t": "息", "c": 0.624652},
       {"d": "2026-12-04", "t": "權", "c": 0, "sr": 0.0812, "sp": null}]
```

| 鍵 | 內容 | 何時出現 |
|---|---|---|
| `d` | 除權息日 `YYYY-MM-DD` | 一定有 |
| `t` | `息`／`權`／`權息` | 一定有 |
| `c` | 每股現金股利（數字，去掉尾端 0）；`null` = 待公告 | 一定有（`0` 和 `null` 意義不同） |
| `s` | 每千股配股 = `stock_ratio × 1000`（去尾 0；R33、Q40-3） | 只在 > 0 時 |
| `sr` | 現增配股率（每股，去尾 0） | 只在 > 0 時 |
| `sp` | 認購價（元）；`null` = 尚未公告 | 只在 `sr` 出現時 |

- 依 `d` 舊到新排序；通常 1 筆。
- 位置：個股 dict 在 `"dv"` 之後；`etf_export` 在 `dv` 之後（`etf_export` 新增最後一個選用參數，預設沒有，舊呼叫不變）。
- **沒有 `nx` 時不輸出鍵**，檔案和改版前逐位元組相同；`latest.json` 不變。
- 是否觸發匯出照舊（D86-5）：預告表和行情同一晚抓，行情有新資料就會匯出，預告一起帶上。

### 股利卡「即將除息」一行 `stock.js`

- 位置：在 F39-3 已找到的股利卡（`h2` 文字「股利與填息」／「配息與填息」）的 `.sec-h` 之後插入 `<div class="small dv-nx">…</div>`，在表格或「沒有紀錄」那句之前。`divHTML` 字面不變。
- 每筆 `nx` 一行（通常 1 行），文字由下列片段組成：
  - 開頭：`即將除息 12/03：`、`即將除權 11/27：`、`即將除權息 12/03：`（`t` 決定）。
  - 片段（依序，有才寫，用「、」連接）：
    - `c` > 0：股票寫 `現金股利 0.624652 元`；ETF 寫 `配息 7 元`（數字照 `nx` 的值，不另外四捨五入）。

    - `c` 是 null：`金額待公告`。
