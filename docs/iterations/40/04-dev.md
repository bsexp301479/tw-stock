## 五、上線步驟（需要使用者同意才執行，PG 沒有執行）

1. `python3 -u -m twstock backup`
2. `python3 -u -m twstock setup-db`（建立 `dividend_notices`；可再跑一次確認重複執行不報錯）。
   - 注意：沒先跑 `setup-db` 就收集，`notices` 寫入會因為沒有資料表而讓這次收集回傳 2（設計第九節的風險）。所以 `setup-db` 一定要在下一次排程前完成。
3. 收集（D87 = A，二擇一）：
   - 交易日晚上行情公布後，手動 `python3 -u -m twstock collect --catch-up`：確認輸出有兩行「📅 上市／上櫃除權除息預告 N 筆」，`collect_runs` 這次的請求數比前一晚多 2。
   - 或在週末 `setup-db` 後，等 11/23（週一）排程自然抓。
4. 視需要 `python3 -u -m twstock export`（收集沒有自動匯出時）。
5. `python3 -u -m twstock check`：有「除權除息預告最後成功：上市 YYYY-MM-DD（N 筆）、上櫃 …」那一行。
6. 抽查 `site/data/stocks/1437.json`、`site/data/etfp/00901.json`、`site/data/stocks/3706.json`（除權息日還沒到的話）有 `nx`。
7. 8001 冒煙測試：1437 基本面股利卡有「即將除息」那一行；`#/tools/dv?c=1437` 帶入預告股利；`#/tools/dt?c=1437` 有「12/03 除權息，參考價另計」；測完關閉 8001。
