## 重點摘要

- **本站資料可以驗出官方參考價的捨入方式，而且上市、上櫃不同**（第 38 輪初評沒發現）：
  - 上市除息：**無條件捨去到 0.01**。股票 830／830、ETF 545／545 筆吻合。例：2330 於 9/16 前收 2,385、息值 7.000001 → 2,377.999999 → 官方 **2,377.99**（四捨五入會得到 2,378.00）。
  - 上櫃：**四捨五入到 0.01**。股票 663／663（含配股 60 筆）、ETF 668／668 吻合。
  - 有現金增資（`k = sc`）的 5 筆兩種都不吻合，公式要加認購價，本站沒有這項資料。
- **官方的息值常有尾數**（2330 7.000001、2063 0.500021）。使用者照新聞填「7 元」，算出來會比官方多 0.01。工具要說明「官方以實際每股金額計算」。
- **上市「權息」拆不出現金與配股**：官方表只有權值＋息值合計（`a`）。最近一次是這種的有 78 檔（上市權息 60、上市純權 18），這些股票帶入時只能給合計與官方參考價，現金與配股要使用者自填。
- 本站**沒有預告資料**：`dv` 都是已除權息的紀錄（未來日期 0 筆）。工具能帶入的是「最近一次」的股利，當作試算起點；要算下一次，得自己填公告的金額。抓「除權除息預告表」要新增收集，列為選項 F39-4。

## 二、需求說明

### F39-1 工具頁「除權息」分頁（`#/tools/dv`）

- 輸入：

| 欄位 | 預設 | 說明 |
|---|---|---|
| 市場 | 上市（帶入時依股票） | 分段鈕「上市／上櫃」，決定捨入方式 |
| 除權息前收盤 | 帶入最新收盤 | 必填 |
| 現金股利（元／股） | 帶入最近一次 | 0 以上 |
| 每千股配股（股） | 帶入最近一次，沒有為 0 | 說明「配股 1 元 = 每千股 100 股（面額 10 元時）」 |
| 持有股數 | 1,000 | 整數 |
| 持有成本（元／股） | 空白 | 選填；填了才算成本殖利率 |
| 近一年現金股利合計 | 帶入（見 F39-2） | 選填；成本殖利率用 |

- 輸出：

| 項目 | 算法 |
|---|---|
| 除權息參考價 | R25，上市捨去、上櫃四捨五入到 0.01 |
| 下一交易日漲跌停 | 沿用 `tlLimit(參考價)`，漲跌幅 10% |
| 可領現金股利 | 持有股數 × 現金股利，元以下捨去（實際以公司發放為準） |
| 配發股數 | 持有股數 × 每千股配股 ÷ 1,000；整數股與不足 1 股分開寫，不足 1 股的部分寫「依公司公告折付現金」（R27） |
| 除權息後的權益 | (原股數＋配股) × 參考價＋現金股利 ≈ 原股數 × 前收：說明「除權息不會讓總價值變多」 |
| 二代健保補充保費 | 單次股利 ≥ 2 萬元 × 2.11%（R11、R26，見 D82-2） |
| 成本殖利率 | 近一年現金股利 ÷ 持有成本；只在填了成本時顯示 |
| 以前收算的殖利率 | 本次現金股利 ÷ 前收（標明是「本次」，不是年度） |

- 不做：現金增資（認購價）、所得稅試算（R19 有兩種計稅方式、級距每年改，列待辦）。

### F39-2 帶入（`?c=代號`）

- 沿用 `tlLoad`，多帶：
  - 最近一次 `dv`：日期、類型、`c`、`s`；畫面寫「已帶入 MM/DD 的股利（最近一次），下次請依公司公告修改」。
  - 官方參考價對照：帶入的前收用**當次的除權息前收盤 `p`** 時，算出的參考價應等於官方 `ev.r`；畫面寫「官方參考價 X」。預設前收是最新收盤（試算下一次），所以預設兩者不同，見 D82-3。
  - 近一年現金股利合計：365 天內「息」「權息」的 `c` 加總；有缺值時寫「部分缺值，請自行確認」。
- 上市「權息」「權」：現金與配股不帶入（只有合計），寫「上市官方表只有權值＋息值合計 X 元，請依公告填現金與配股」。
- `k = sc`：寫「含現金增資，參考價請看官方公告」。
- ETF：帶入 `dv` 的 `c`，配股固定 0。

### F39-3 卡片連結

## 五、用詞
