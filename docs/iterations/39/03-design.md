## 二、程式設計

### 2-1 整數單位（`tools.js`）

| 數值 | 單位 | 輸入小數上限 |
|---|---|---|
| 前收、持有成本 | 分（× 100） | 2 位 |
| 現金股利、近一年合計 | 10^-6 元 | 6 位（本站資料最多 6 位） |
| 每千股配股 | 10^-8 股 | 8 位（本站資料最多 8 位） |
| 持有股數 | 股 | 整數 |

- 全部用 `BigInt`（`tlFee`、`tlPledge` 已有先例），所以金額再大也不會溢位。
- 輸入字串直接轉整數（`tlBig`），不經過浮點。
- 參考價 `tlExRef(P, C, S, tw)`：
  - 分子 `(P × 10^4 − C) × 10^11`，分母 `(10^11 + S) × 10^4`，結果的單位是分。
  - 上市而且沒有配股時用整數除法（捨去），其他情況四捨五入：`(2 × 分子 + 分母) ÷ (2 × 分母)`。

### 2-2 輸出（`tlDvOut`）

| 列 | 算法 |
|---|---|
| 除權息參考價 | `tlExRef` |
| 下一交易日漲跌停 | `tlLimit(參考價, ETF?)`，和交易成本頁共用 |
| 可領現金股利 | 股數 × C，元以下捨去 |
| 配發股數 | 股數 × S 的整數部分；另一行「另有不足 1 股 0.99999376 股」 |
| 除權後股數 | 股數＋整數配股 |
| 除權息前市值 | 股數 × 前收 |
| 除權息後市值＋現金股利 | (股數＋配股含不足 1 股) × 參考價＋股數 × 現金，四捨五入到元 |
| 二代健保補充保費 | 可領現金 ≥ 20,000：min(可領現金, 10,000,000) × 2.11%，四捨五入到元；否則「未達 2 萬元，不扣」 |
| 本次現金股利 ÷ 前收 | 現金 > 0 才顯示 |
| 成本殖利率（近一年 ÷ 成本） | 有填成本與近一年合計才顯示 |

- 結果表下方依序列出：帶入提示 → 漲跌停算法 → 「除權息前後的總價值相同，差額來自參考價捨入到 0.01」→ 四則規則說明 → 頁尾免責。
- 驗證：每個欄位有自己的訊息；有任何訊息時不出結果表。
  - 現金和配股空白都當作 0；兩者都是 0 時寫「請輸入現金股利或配股」。
  - 現金 ≥ 前收時寫「現金股利須小於除權息前收盤」。
  - 可以輸入千分位（`1,000`）。

### 2-3 表單（`tlDvForm`）

- 分段鈕：上市／上櫃、股票／ETF（ETF 用來決定升降單位，見 D84-2）。
- 輸入欄（6 個）：除權息前收盤（元）、現金股利（元／股）、每千股配股（股）、持有股數、持有成本（元／股）、近一年現金股利（元／股）。
- placeholder：現金與配股「空白 = 0」，成本與近一年合計「選填」。

### 2-4 帶入（`tlDvLoad`，`tlLoad` 只在最後加 3 行）

| 情況 | 帶入 | 提示 |
|---|---|---|
| 一般（上市息、上櫃息／權息／權、ETF、上市權有 `s`） | `c`、`s`（沒有的當 0） | 「已帶入 MM/DD 的股利（最近一次），下次請依公司公告修改」 |
| 上市權息只有 `a` | 不帶 | 「上市官方表只有 MM/DD 的權值＋息值合計 X 元，請依公告填現金股利與配股」 |
| `k = sc` | 不帶 | 「最近一次（MM/DD）含現金增資，參考價請看官方公告；現金股利、配股沒有帶入」 |
| 沒有紀錄 | 只帶前收、市場 | 「YYYY-MM-DD 起沒有除權息紀錄，請依公司公告填寫」（和股利卡同一說法） |
| 有官方參考價 | — | 「上次官方參考價 X（MM/DD，前收 Y）；前收改成 Y 可對照」 |
| 近一年合計 | 最新交易日往前 365 天以後的「息」「權息」`c` 加總（純「權」不計） | 「近一年現金股利 = MM/DD 以後 N 次合計」；有缺值時加「；部分缺值，請自行確認」；全部缺值時寫「MM/DD 以後的現金股利官方表沒有分項，請自行確認」 |

- 一律帶入：前收 = 最新收盤（D82-3 = A）、市場、股票／ETF。
- 持有成本：不帶入，換股票時清空（D83-1 = A、D84-1）。持有股數則保留使用者填的值。
- `tlLoad` 既有欄位（`TL.info` 的 code～ex、`TL.dt`、`TL.pl`、`TL.cp.y`）不變，只多一個 `TL.info.dvh`（提示文字）。
