## 一、本輪目標

- 工具頁多一個「除權息」分頁，回答三個問題：
  - 除權息後參考價是多少、隔天漲跌停在哪裡？
  - 我持有的股數可以領多少現金、配多少股？
  - 用我的成本算，殖利率是多少？
- 從個股頁、ETF 頁的股利卡一鍵帶入最近一次股利。
- 結果和本站官方參考價資料一致（上市、上櫃捨入不同），並寫清楚哪些情況算不準。

### F39-1 分頁

- 分頁名稱「除權息」，放在「股票質借」之後（第 4 個）。
- 輸入（全部用既有 `tlIn`、`tlSeg`）：

| 欄位 | 預設 | 驗證 |
|---|---|---|
| 市場（上市／上櫃） | 上市；帶入時依股票 | — |
| 除權息前收盤（元） | 帶入最新收盤，否則空白 | > 0，小數最多 2 位 |
| 現金股利（元／股） | 帶入最近一次，否則空白 | ≥ 0；小數位數由 SA 定（官方有 6 位以上尾數） |
| 每千股配股（股） | 帶入最近一次，否則 0 | ≥ 0 |
| 持有股數 | 1,000 | 正整數 |
| 持有成本（元／股） | 空白 | 選填，> 0 |
| 近一年現金股利（元／股） | 帶入合計，否則空白 | 選填，≥ 0 |

- 現金股利、配股都是 0 → 訊息「請輸入現金股利或配股」，不出結果。
- 輸出：

| 項目 | 規則 |
|---|---|
| 除權息參考價 | (前收 − 現金) ÷ (1 + 配股 ÷ 1,000)；上市無配股捨去到 0.01，上市有配股與上櫃四捨五入到 0.01；**整數運算**（1102：34.8 − 2.3 = 32.50） |
| 下一交易日漲跌停 | 沿用 `tlLimit`，以參考價為基準 |
| 可領現金股利 | 股數 × 現金，元以下捨去 |
| 配發股數 | 股數 × 配股 ÷ 1,000：整數股、不足 1 股分開寫 |
| 權益對照 | 除權息前市值（股數 × 前收）與除權息後（(股數＋整數配股) × 參考價＋現金＋不足 1 股的部分）兩行並列，說明差額來自參考價捨入與畸零股 |
| 二代健保補充保費 | 可領現金 ≥ 20,000 元 → × 2.11%，元以下四捨五入（SA 查證捨入）；未達寫「未達 2 萬元，不扣」 |
| 本次股利 ÷ 前收 | 現金 ÷ 前收，寫明「本次」 |
| 成本殖利率 | 近一年現金 ÷ 持有成本；兩者都有值才顯示 |

- 說明（短句可見、完整收合，沿用 `tlNote`）：
  - 「參考價依證交所、櫃買中心公式；上市除息捨去、上櫃四捨五入到 0.01（本站用過去一年官方資料驗算）。」
  - 「官方以實際每股金額計算（常有小數尾數），只填到元或角時可能和官方差 0.01。」
  - 「不含現金增資；有現增時參考價請看官方公告。」
  - 「股票股利以面額計入補充保費門檻（面額依公司而定），本頁只算現金。」
  - 「不足 1 股依公司公告折付現金，可在期限內湊股。」
  - 頁尾沿用 `TL_FOOT`＋「本站不提供投資建議。」
