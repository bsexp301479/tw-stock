## 四、觀察（不算缺陷）

1. **極大金額的浮點顯示**：除權息前市值超過約 10 兆元時，`fmt(分 ÷ 100)` 的末位可能差 0.01 元。例：股數 919 萬 × 前收 796 萬元 → 73,179,210,754,710.98，正確是 .99。這和第 38 輪觀察 2 是同一類浮點限制，參考價、配股不受影響，一般使用不會遇到這種金額。
2. **參考價為 0**：前收 1、現金 0.999999 這類輸入，上市捨去後參考價是 0.00，漲跌停顯示 0.00。現金 ≥ 前收時已有擋，但參考價 < 0.01 時沒有提示。實際股票不會有這種情況；要擋可以加一則訊息。
3. **`1,5` 會被當成 15**：逗號被當成千分位。這和交易成本、複利、質借三頁的既有行為一致。
4. **完整名稱＋Enter 不送出**：只有完整「代號」會直接進入。輸入「台積電」時候選只有 1 筆，但仍要按 ↓ 或點選。這符合使用者說的「完整代號」；若也要接受完整名稱，可以另外加。
5. **320 寬時「除權息」分頁一半在分頁列外**：從股利卡點進來時，目前所在的分頁標籤只露出一半（分頁列可以左右捲動）。符合驗收 13；要改可以讓目前分頁自動捲進可見範圍。
6. 主控台只有 `ERR_CONNECTION_REFUSED`，是分頁在 8001 停止期間留下的；測試期間沒有 JavaScript 錯誤。
