## 五、缺陷與觀察

### 缺陷

**QA29-02（輕微，文件）證交所主機被標記時，影響不只 `breadth.TWSE`**

- 設計 3-3 與第四節風險 3 寫：外資持股排在證交所請求最後，萬一主機被標記，「只影響後面的 `breadth.TWSE`（用快取，不發請求）」。
- 模擬結果：`MI_QFIIS` 失敗（重試用完）、證交所被標記後，同一次執行**之後**還有幾項證交所請求也不會發：
  - 上市注意股（`announcement/notice`）：輸出「上市注意股抓取失敗，本次略過…下次收集會補最近 30 天」。
  - 除權息／減資／面額變更事件（`TWT49U`、`TWTAUU`、`TWTB8U`）：輸出「events 失敗」。
- 櫃買 `insti/qfii` 失敗時也一樣，同一次執行的櫃買指數（`index.TPEX`）與櫃買事件也不會抓。
- 這不是新的程式缺陷：
  - 機制是 `fetch` 原本的保護。
  - 第 11 輪的借券（`sbl.*`）原本就有同樣的連帶影響。
  - 下一次排程會補，而且要重試 3 次（約 3.5 分鐘）都失敗才會標記，那時主機多半真的被封鎖。
- 這輪的影響：每晚多 1 個證交所、1 個櫃買請求，觸發連帶影響的機會略增。
- 建議：
  - 只修文件，不改程式。
  - 設計 3-3、第四節風險 3 改成「同一次執行之後的上市注意股、除權息事件（櫃買則是櫃買指數、事件）也會略過，下一次排程補」。
  - README 的外資持股段可以加同一句。

### 不列缺陷的觀察

1. **停牌期間的外資持股不會顯示**：
   - `fh` 對齊 `prices.d`，停牌日（沒有行情）的 896 列不匯出。
   - 卡片顯示最後交易日的比率，並在副行寫日期，例如 1589「04/02」。
   - 「5 日、20 日」是往前 5／20 個**有行情的日子**，停牌股會跨過停牌期間。
   - 這是設計（對齊 `prices.d`）的結果，畫面有標日期。
2. **官方比率是無條件捨去**到 2 位，不是四捨五入。所以「比率 ≈ 持有 ÷ 發行」的差介於 0～0.01（≥ 0.006 的有 199,799 列），設計第八節用「< 0.01」判斷是對的。
3. **尚可投資 ＋ 持股比率 ≠ 上限**的有 2,957 列（差 > 0.02），例如 2321 持股 0.01%、尚可 0.00%、上限 100%。這是官方原值，畫面沒有用這兩欄。
4. **整段都是 null 的 `fh`**：如果某檔的外資持股日期全部不在 `prices.d`，匯出會輸出全部是 null 的 `fh`，頁面不顯示卡片，但會畫一張空的持股比率圖。目前 **0 檔**，只記錄。
5. **櫃買 22:00 版不重抓**（設計風險 1）：SA 11/16 約 23 點的回應和之後回補的資料全欄相同，但 18:00 版和 22:00 版的差異仍要等上線後觀察。
6. **README 的回補時間**寫「約 30 分鐘」，實際 15.3 分鐘（PG 已記錄）。不影響使用。
