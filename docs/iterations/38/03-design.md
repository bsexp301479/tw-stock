- 對照線：同參數再呼叫一次 `tlCompound`，只把 `re` 反過來（`re: out`），函式不改。
- 線 3 用點線而非 PM 寫的「細實線」：`--blue` 和 `--violet` 色相接近，色覺差異者靠線型也能分辨（D81）。
- 畫線順序：格線 → 線 3 → 線 1 → 線 2（虛線最後畫，`r = 0` 時與期末金額重疊仍看得到）。

### 4-3 座標與取整

- `viewBox="0 0 100 100"`、`preserveAspectRatio="none"`、所有線 `vector-effect="non-scaling-stroke"`（同 `spark`）；CSS `height:160px`、`width:100%`。
- X：`i / n × 100`，`toFixed(2)`；`n ≥ 1` 由驗證保證，不會除以 0。
- 最大值 `mx` = 所有線、所有年的最大值。`P + M > 0` 且 `r > -100` 時每個值都 ≥ 0，且第 0 年或第 n 年的累計投入 > 0，所以 `mx > 0`。
- 格線間距 `step`：不小於 `mx ÷ 4` 的最小 `1、2、5 × 10^k`，**至少 1 元**；`top = ceil(mx ÷ step) × step`，格線 1～4 條（`k × step`，`k = 1…g`）。例：`mx` 2,648,109 → `step` 1,000,000、`top` 3,000,000。
- Y：`2 + (1 − v ÷ top) × 96`，`toFixed(2)`；上下各留 2，線寬不被裁掉。0 軸 `--border2`，其他格線 `--border`（裝飾用，不承載數字）。
- 縱軸從 0 起；`top ≥ mx`，所有座標都在 0～100。

### 4-4 數字（SVG 外的 HTML）

- 圖例 `<span class="lg"><i class="d"></i>累計投入 <b>1,200,000</b> 元</span>`：
  - 線 1：不計股利、再投入 = `fmt(期末金額)`，和摘要表「期末金額」逐字相同；領出 = `fmt(Math.round(期末) + Math.round(已領))`，等於摘要表兩格相加（不會差 1 元）。
  - 線 2 = `fmt(累計投入)`，和「投入本金合計」逐字相同。
  - 線 3 = 同一規則套在對照計算的最後一列。
- 座標說明「第 0～n 年；縱軸 0～{top} 元，每格 {step} 元」：PM 要的「最大值也標在 HTML」以縱軸上限表達（實際最大值就是圖例第一個數字）。
- 圖例 `i` 用 `border-top`（實線、`dashed`、`dotted`），**不用 `background`**；`.lg i` 原本就沒有背景色。
- SVG 裡沒有 `<text>`，沒有 `fill`（除 `fill="none"`）、`polygon`、`path`、`rect`、`gradient`、`fill-opacity`、行內 `style`；不用 `--up`、`--dn`。
- 顏色都是 `stroke="var(--…)"`，切換深淺色時由 CSS 變數生效，不必重畫（實測切換 `data-theme` 後 `getComputedStyle(polyline).stroke` 直接變色）。
