### F38-3a 複利成長圖

- 位置：複利結果的摘要表之下、逐年表之上。
- 線（D78-1 = A）：
  - X 軸從第 0 年到第 n 年。第 0 年 = 初始金額，兩條線在同一點起；第 1～n 年取 `tlCompound` 的每一列。
  - 線 1「期末金額」：實線，`--blue`。股利領出模式畫「期末金額＋已領股利」，標籤寫明。
  - 線 2「累計投入」：虛線，`--text2`。
  - 線 3（只在開股利時）：另一種股利處理方式的對照線，`--violet` 細線。用同一個 `tlCompound` 多算一次，不改函式。
- **不塗色**（D78-2 = A）：本站迷你圖都是 `fill="none"` 的 `polyline`，第 37 輪河流圖也只畫線（D66-5 = A）。塗色容易被讀成「獲利區」；也不用紅／綠。
- 顏色都用 CSS 變數，深淺色切換時不用重畫。
- 數字放在 SVG 外的 HTML：圖下圖例寫每條線第 n 年的金額，`fmt` 與表格同一格式；最大值也標在 HTML。SVG 不放文字，因為 `preserveAspectRatio="none"` 會把文字拉變形。
- Y 軸從 0 起。`P + M > 0` 已由驗證保證，最大值一定 > 0，不會除以 0。驗證不通過時不顯示圖。SVG 設 `aria-hidden="true"`，內容由圖例文字表達。
