  - 「ETF 另計」獨立一小段。
  - 口徑說明（「不等於看空」「140% 是經驗值」）收進既有的「說明」。

### U30-05 市場寬度卡換行後失去市場標籤（低～中｜純呈現）

### U30-06 資金象限四格只連到泡泡首頁（低～中｜純呈現）

  - 沿用今日頁目前選的類股／產業鏈／概念股。
  - 不新增篩選功能也可以：捲到第一個屬於該象限的列並標示即可。

### U30-07 「差一次」15 檔串成一段文字（低～中｜純呈現）

- 375 實測，處置／注意展開後的「接近處置（推算）」：
  - 「已達條件」2 檔是一檔一列（名稱、代號、市場、條件）。
  - 「差一次」15 檔卻是一整段：「差一次：精材（第 1～8 款連 4 日）、世芯-KY（第一款連 2 日）、營邦（第一款連 2 日）…」。

  - 改成和「已達條件」一樣一檔一列，右邊寫「差 1 次」。或改成兩欄小標籤，每個至少 32px 高。
  - 用詞統一為「第 1 款」「第 1～8 款」。
  - 括號改寫成「已連 2 日」這類明確的說法。具體用詞交給設計師。

## 四、泡泡圖清單（U30-08、U30-10）

### U30-08 展開成分股是頁內捲動框（低～中｜純呈現）

- 手機上手指在框內滑，是框內在捲；滑到框的邊界又變成整頁在捲。兩層捲動互搶，最後一列「興泰」只露出半列。
- 建議：

### U30-10 四捨五入成 0 仍上漲跌色（低｜純呈現）

- 375 泡泡清單：「農業科技　0億」顯示紅色（上漲色）；食品成分股「大研生醫　法人1日 0億」也是紅色。
- 原因：顏色用原始值判斷（`cls = n => n > 0 ? 'up' : …`），文字卻四捨五入成 0。原始值是 +0.04 億，顏色是紅、字是 0。
- 同頁「日均差 0.0」是灰色，同一張表出現兩種 0。
- 建議：顏色依**顯示出來的數字**判斷，顯示 0 就用灰色；或顯示成「+0.04億」。範圍：泡泡清單、成分股表、今日法人表。由設計師盤點有哪些格式化函式。

## 七、給 UI/UX 設計師的限制

1. 只改 `site/`，不改 `twstock/`、`site/data`，不新增資料欄位與 localStorage 鍵（必要時說明理由，交使用者決定）。
