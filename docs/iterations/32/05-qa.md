## 四、觀察（不列缺陷）

1. **手機開不了 `localhost` 連結**：同設計第八節觀察 1，是已知限制。
2. **略過的代號顯示成 `%3CIMG%20SRC` 這種編碼字**：
   - 瀏覽器會把網址裡的特殊字元編碼，網站照原樣顯示（安全，只是不好讀）。
   - 正常分享出來的連結只有英數字，不會遇到。
3. **連結被其他 App 把逗號編碼成 `%2C` 時，整串會被當成一個不認得的代號**：
   - 目前常見的通訊軟體不會這樣做，本輪沒有實測到。
   - 若以後遇到，`route()` 解析前加 `decodeURIComponent` 即可。
4. **剪貼簿成功路徑**：
   - 「已複製分享連結」只在設計階段用真實點擊驗過。
   - QA 沒有再按一次，避免再覆蓋系統剪貼簿。程式路徑由 `test_iter32.test_share_source` 檢查。
5. **在「表現」或「基本面」時刪光所有股票**：空清單畫面不會顯示「1日／5日」。只有這個邊角情況會這樣，不影響使用。
