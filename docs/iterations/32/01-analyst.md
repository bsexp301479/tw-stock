## 二、動線實測發現

### 2-1 自選頁只看得到「法人資金」（→ F32-1）

- 375 寬自選 5 檔股票＋2 檔 ETF 的實測：
  - 欄位固定是：收盤、漲跌、成交額、外資／投信／自營／法人 1 日（或 5 日），外資連、投信連、法人連。
  - 下面是「近期新訊號、處置／注意」。
- 持有或追蹤一檔股票的人，每天最常問的問題，自選頁目前都答不出來，要逐檔點進個股頁：

  | 問題 | 需要的欄位 |
  |---|---|
  | 這幾天跌了多少 | 5／20／60 日報酬 |
  | 離高點多遠 | 距 52 週高 |
  | 在均線上還是下 | MA20 乖離 |
  | 營收、估值現在怎樣 | 營收年增、本益比、殖利率 |

- 這些都已經在 `latest.json`（`h52`、`pe`、`dy`）或 `screen.json`（`r5`、`r20`、`b20`、`ry`、`ey`）裡。
- 做法方向：
  - 自選頁的「1日／5日」旁加一組分段鈕「資金／表現／基本面」，換欄位組。
  - 表現：5 日、20 日、60 日報酬，距 52 週高，MA20 乖離。
  - 基本面：營收年增（月份）、單季 EPS 年增、本益比、殖利率、淨值比一年位置。
  - 選擇記在既有的 `tw.rspan` 或只存在記憶體，**不新增 localStorage 鍵**（PM 決定）。
  - `screen.json` 在排行、選股頁已有載入流程，自選頁沿用；載入失敗時只顯示「資金」欄組。
- 用詞：報酬、乖離只描述數字，不加「超跌」「強勢」之類的字。

### 2-2 自選清單換裝置不會同步（→ F32-2）

- 自選頁自己寫著「存在這個瀏覽器裡，換裝置不會同步」。
- 使用者有 8000（電腦）與手機兩種情境。網站沒有後端，不可能自動同步，但可以用連結搬：
  - 自選頁加「分享清單」按鈕，產生 `#/watch?add=2330,2317,…` 連結。手機可用系統分享，電腦可複製。
  - 開啟這種連結時，**先顯示「要加入以下 N 檔嗎？」，按「加入」才寫入**。不自動覆蓋，避免誤點連結就弄亂清單。
  - 加入後把網址換回 `#/watch`，重新整理不會重複詢問。
- 邊界：
  - 不認得的代號略過，並列出略過哪些。
  - 已在清單的不重複。
  - 上限比照現有自選（無上限，但連結長度建議 ≤ 200 檔）。
- 不新增 localStorage 鍵，寫入既有 `tw.watch`。

### 2-3 股利資料只在個股頁（→ F32-3，待辦 F24-6-延伸）

- 第 24 輪做了「股利與填息」卡：個股 JSON 的 `dv` 有除權息日、現金股利、填息日、第幾天填息。
- 但選股、排行都不能用：

  - 殖利率條件（`dy`）已經有，但不知道填息狀況。
- 要做的話：
  - `export.py` 在 `screen.json` 加 2～3 欄：
    - `dvf`：最近一次除息是否已填息。
    - `dvn`：填息天數。
    - `dvd`：最近除息日。
  - 選股「基本面」組加條件，排行加「填息天數」。
- 資料面：`dividends()` 已經在匯出端算好，只是多寫幾欄，**不動資料庫、收集器**。
- 風險：要改 `export.py`，而且要跑一次 `export` 才看得到。
  - 第 24 輪觀察的是收集與「沒有新資料不重複匯出」的判斷，和匯出內容無關，干擾低。
  - 但仍是「11/19 前改匯出」，交給使用者決定（D40）。

### 2-5 估值只有「一年位置」，沒有走勢（→ F32-5，待辦 F22-9）

- 個股 JSON 的 `val` 只有 `[位置%, 一年低, 一年高]`，基本面看不到本益比過去一年怎麼走。
- 要畫本益比河流圖或本益比線，`export.py` 要在個股 JSON 加每日 `pe` 序列。
  - 約 253 天 × 每檔 2～3 KB，2,000 檔合計約 +5 MB。
  - 只在開個股頁時下載。

### 2-6 今日頁沒有一句話摘要（→ F32-6）

- 今日總覽第一屏有指數、法人、期貨、融資、成交額、寬度共 8～10 張小卡。
- 新手要讀很多卡才知道「今天大致怎樣」。
- 可以用既有數字組一句描述，例如「加權 −2.31%、上市法人 −576 億、上市 20 日新低 449 檔」。
- 只是把卡片上的數字再寫一次，資訊增量小；而且自動生成的句子容易被讀成評論，用詞風險較高。
- 重要度低。
