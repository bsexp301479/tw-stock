## 六、與設計的差異

1. **程式：沒有差異**，附錄 A 原樣套用。
2. **基線資料夾**：任務說明寫「把 site/data 複製到 `logs/iter14_before/`」，設計第十一節是程式檔放 `logs/iter14_before/`、資料放 `logs/iter14_base/`（`iter14_compare.py` 的用法也是這個路徑）。依設計分開放。

4. **設計文字小誤（程式正確，只記錄）**：
   - 第 3-4 節寫近 60 日迷你圖「有 2 條換月虛線」，實際有 **3 條**（08/20、09/17、10/22 都在 08/10～11/06 內）。程式依資料正確畫出 3 條。
   - 第十一節 `collect_runs` 的欄名是 `run_id`，不是 `id`。
5. README 的行數：設計寫 ＋4／−1，實際 diff 是 ＋4／−4，因為 3 段是改寫既有段落（句末加字），1 段是新增。內容和附錄 A 相同。
