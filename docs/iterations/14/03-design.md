## 三、F14-3 期現貨價差、結算日、換月

### 3-1 價差：同日對齊

- 價差 = 台指期近月**日盤**收盤 − **同一天**加權指數收盤。夜盤不比。
- 「近月」沿用 `_load_futures`：當天有收盤的最近到期月份。**不改近月規則**：結算日當天仍是到期月份。
- 對齊方式：`futures.d` 的每一天，用同一個日期字串去找 `market_index` 的 `TAIEX` 收盤。
  - 任一邊沒有收盤 → `null`（不補、不估，也不拿前一天的加權指數）。
  - 期貨資料日比加權指數新（例如加權指數還沒收）→ 最新一天的 `sp` 為 null，期貨卡寫「價差 --（加權指數沒有同一天的收盤）」，不退回舊日期的價差。
- `futures.sp` 和 `futures.d` 一樣長（500 個），四捨五入 2 位。
- **加權指數的起日是 2025-10-30**（`market_index` 實際有 247 天），不是 PM 文件寫的 2026-02-23。所以 2025-10-30 起都有價差，之前（2024-10-16～2025-10-29）為 null（第十三節第 3 點）。

### 3-2 結算日函式（`export.py`，可單元測試）

```python
def settle_day(y: int, m: int, closed) -> date:
    """台指期 y 年 m 月契約的結算日（本站推算）：第三個週三；遇休市順延到下一個交易日。closed = 休市日集合。"""
    d = date(y, m, 15 + (2 - date(y, m, 1).weekday()) % 7)         # 第三個週三落在 15～21 日
    while not is_trading_day(d, closed):
        d += timedelta(days=1)
    return d


def next_settle(d: date, closed) -> dict:
    """資料日 d 之後（含當天）的下一個結算日 {d, n}；n = d 之後到結算日（含）的交易日數，0 = 今天結算。"""
    s = settle_day(d.year, d.month, closed)
    if d > s:
        s = settle_day(d.year + d.month // 12, d.month % 12 + 1, closed)
    return {"d": str(s), "n": len(trading_days(d + timedelta(days=1), s, closed))}
```

- 休市集合：匯出時讀一次 `tradingcal.load_closed(cur)`（官方表＋手寫表＋臨時休市，和 `check` 相同），只讀不寫。
- 資料日用**期貨最後一天**（`futures.d[-1]`），因為期貨卡顯示的是期貨資料日。
- 剩餘交易日 `n` = 資料日之後、到結算日（含）的交易日數。資料日 = 結算日 → 0（「今天結算」）。資料日已過當月結算日 → 下個月（12 月跨到次年 1 月）。
- **用實際資料驗證**：`futures.m` 從 2024-10 到 2026-11 共 25 次換月。每次換月前一個交易日，都等於 `settle_day(舊契約年, 月, 休市)`，**25／25 相符**，其中包含 2026-02-23 春節順延。
- 單元測試（不連資料庫，休市集合用測試資料；第九節）：

  | 情況 | 輸入 | 結果 |
  |---|---|---|
