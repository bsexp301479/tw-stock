## 二之二、頁面規格

### 版面（`#/help`）

1. 一張卡：
   - 標題 `<h2>名詞說明</h2>`。
   - 下一行小字：`本站各頁用到的名詞與本站的算法；官方或其他網站的定義可能不同。`
   - 下一行 8 個分組按鈕（`.chip`，文字＝組名），連到 `#/help/組代號`。
2. 每組一張卡（`<section class="sec card" id="help-組代號">`），標題 `<h2>組名</h2>`。
3. 每個名詞一列（`id="help-代號"`）：`<b>名詞</b>` 換行接定義；有連結時定義後接 `　<a href="…">看 X →</a>`（全形空白後接）。
4. 頁面最後一行小字：`名詞說明只描述算法與定義，不構成投資建議。`
5. 名詞、定義都是固定文字，**不使用資料**；頁面不需要等 `latest.json` 以外的資料。
