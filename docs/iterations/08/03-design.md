### 1-2 單位數 1 日變化（P21 數字）

  - `u1 = round((最新持股日 units ÷ 前一持股日 units − 1) × 100, 2)`，單位 %。

### 1-3 投信買超中的主動 ETF（B16）

**匯出 `active_trust(holdings, tw, flow_date)` → `{股票代號: 張數增減合計}`**：

1. 只取 **delay 0（國內）**、**最新持股日 = 法人資料日**（`flow_date` = `latest.json` 的 `flow_date`）、且至少有兩個持股日的 ETF。
   - 跨境（00411A、00988A、00997A）一律不計入：持股日晚一天，而且它們買的台股交易日和 T86 不同日。
   - 國內 ETF 當天還沒收到持股（停在前一天）→ 該檔不計入，其他已收到的照算。
2. 每檔 ETF：最新持股日張數 − 前一持股日張數（股 ÷ 1000 四捨五入，和 `holding_table` 相同；沒持有算 0）。**含新進與出清**。只算 `stocks` 表裡的台股。
3. 各 ETF 加總；合計為 0 的股票不列（所以只有跨境 ETF 有變動的股票不會有 `act`，PM #5）。

**`trust_share(t, e)`**：同向（都 > 0 或都 < 0）且 |e| ≤ |t| → `round(e ÷ t × 100)`（整數 %，Python 四捨五入）；其他（投信 0、反向、主動 ETF 超過投信合計）→ `None`。

**個股 JSON 新鍵 `act`**（只在有合計、且法人資料日有投信張數時才有）：

```json
"act": {"d": "2026-11-04", "t": 850, "e": 836, "p": 98}
```

| 鍵 | 意義 | 來源 |
|---|---|---|
| `d` | 法人資料日 | `dates[-1]` |
| `t` | 當天投信買賣超（張） | 該股 `institutional_trades.trust_net` ÷ 1000 四捨五入，和 `insti.t` 同一個值 |
| `e` | 已收國內主動 ETF 張數增減合計 | `active_trust` |
| `p` | 占比 % 或 null | `trust_share(t, e)` |

### 2-3 `screen.json` 規格

**位置**：`site/data/screen.json`。**欄式**：每個欄位是和 `codes` 同序的陣列。

```json
{"d": "2026-11-04", "fd": "2026-11-04", "md": {"TWSE": "2026-11-04", "TPEx": "2026-11-04"},
 "rmd": {"202609": 1975, "202608": 5},
 "codes": ["1101", "1102", …],
 "a20": [15.62, …], "vr": [0.99, …], …}
```

**檔頭**

| 鍵 | 意義 |
|---|---|
| `d` | 行情日 = `latest.json date` |
| `fd` | 法人資料日 = `latest.json flow_date` |
| `md` | 各市場最新融資融券日 `{TWSE, TPEx}`；該市場沒有資料時沒有這個鍵 |
| `rmd` | 各營收月份的檔數 `{"YYYYMM": 檔數}`，月份新到舊 |
| `codes` | 和 `latest.json stocks` 相同的代號（今天有資料列且有成交過），依代號排序 |

**欄位**（`SCREEN_KEYS` 依此順序；小數一律 `round(x, 2)`；**算不出來一律 null**）

| 鍵 | 名稱 | 單位 | 公式（`price_stats` 等，附錄 C） | null 條件 |
|---|---|---|---|---|
| `a20` | 20 日平均成交額 | 億 | 該股最近 20 個資料列的成交額平均（含今天；無成交日以 0 計） | 資料列 < 20 |
| `vr` | 量比 | 倍 | 今天成交額 ÷ 前 20 個資料列的平均（無成交日以 0 計入） | 前面不足 20 列，或前 20 列合計 0 |
| `r5`、`r20`、`r60` | N 日報酬 | % | 最後成交的還原收盤 ÷ 基準收盤 − 1。基準日 = **全市場**第前 N 個交易日（`b_days[-1-N]`），基準收盤 = 該股在基準日（含）之前最後一個有成交的還原收盤 | 該股第一筆日線晚於基準日（新上市） |
| `rs20`、`rs60` | 相對大盤 | 百分點 | 未四捨五入的 `rN` − 指數 N 日報酬（同一個基準日）。上市對 `TAIEX`、上櫃對 `TPEX`，以 `stocks.market_type` 為準 | `rN` 為 null，或指數缺資料日或基準日 |
| `b20`、`b60` | 均線乖離 | % | 最後成交的還原收盤 ÷ 最近 N 個**有成交**的還原收盤平均 − 1（和市場寬度卡同一個均線定義） | 有成交的收盤 < N 個 |
| `nh`、`nl` | 創 N 日新高／新低 | 日數 | N 依序試 240、120、60、20，取第一個「今天還原收盤 > 前 N 個有成交收盤的最高」（新低為 < 最低）。都不符合 = 0 | 不會是 null；今天無成交 = 0；有成交的收盤 ≤ N 個時該 N 不成立 |
| `rm` | 營收月份 | YYYYMM | 該股**自己**最新一筆月營收 | 沒有月營收 |
| `ry` | 營收年增 | % | 該月 `revenue_yoy` | 同上，或官方為 null |
| `rc` | 累計年增 | % | `_revenue_rows` 的累計年增 | 同上，或缺月份 |
| `rh` | 營收創新高 | 年 | `_revenue_rows` 的新高年數；0 = 不是新高 | 沒有月營收 |
| `r3` | 連續 3 個月年增 | 0／1 | 最近 3 筆是連續 3 個月，且年增都 > 0 | 沒有月營收 |
| `cap` | 90 天內股本變動 | 0／1 | `_cap_event(ev, latest_date)` 不是 None（`CAP_TYPES`、參考價變動 ≥ 10%、事件日距資料日 ≤ 90 天） | 不會是 null |
| `mb`、`sb` | 融資、融券餘額 | 張 | 該市場最新融資融券日的官方餘額 | 該股當天不在融資融券清單，或該市場沒有融資融券資料（以下融資融券欄同） |
| `m1`、`s1` | 1 日增減 | 張 | 官方今日餘額 − 官方前日餘額（和個股 JSON `margin` 相同） | 同上 |
| `m5`、`s5` | 5 日增減 | 張 | 今日餘額 − 5 個融資融券日前的餘額 × 換算係數（第 3-2 節；沒有換算時係數 1） | 同上，或 5 日前沒有列 |
| `sr` | 券資比 | % | `short_ratio(sb, mb)` | 融資 0 |
| `mu` | 融資使用率 | % | `usage(mb, 限額)` | 限額 0 或空 |
| `mnt` | 停資停券註記（上市） | 字串 | 上市 `note` 原文（例如 `OX`）；上櫃一律 null | 沒有註記 |

- **還原價格**：沿用個股 K 線、52 週高低與市場寬度的 `_adj_factors`（向後還原，最新收盤不變），所以除權息、減資、面額變更都不會造成報酬、乖離、新高新低的跳動。
- **量比用成交額**：面額變更時股數與股價反向變動，成交額不受影響，不必等成交量還原。
- **停牌（沒有資料列）**的日子不在該股的資料列中：`a20`、`vr`、均線、新高新低以「該股自己的資料列／有成交的收盤」計算；報酬以「全市場交易日」找基準日。寶雅 5904 7/30～8/7 停止買賣就是這種情況。
- **今天無成交**（`latest.json` 有 `nt`）：報酬、乖離用最後成交收盤；`vr` = 0；`nh`、`nl` = 0。預設的「排除今日無成交」會把它們排除。

### 2-6 畫面：條件選股 `#/rank/screen`

#### 路由與 hash

- `routes.rank = arg => arg && arg.startsWith('screen') ? renderScreen(arg.slice(6)) : renderRank(arg)`。
  - `route()` 以 `/` 切 hash，所以條件放在 `?` 之後、值裡不能有 `/`：`#/rank/screen?s=3&rh=1&tv=0.5&xd=1&xn=1&xc=1&o=tv`。
  - 參數名 = 條件 id（下表）、值 = 門檻數字（開關型為 `1`）；另有 `o`（排序欄）、`od`（`a` 遞增；省略為預設方向）、`p`（目前套用的預設 id，只用來標亮按鈕）。不認得的參數忽略。
- **條件來源的優先順序**：hash 有 `?` → 只用 hash 的條件（**不和預設合併**，所以關掉的排除條件也能分享）；否則 `localStore('screen')`（JSON）；否則預設 `{xd: 1, xn: 1, xc: 1}`、排序 `tv`。
- 每次變更：`localStore('screen', null, JSON.stringify(state))`，並用 `history.replaceState(null, '', '#/rank/screen?' + 參數)` 更新網址（**不觸發** `hashchange`，畫面不整頁重繪、不跳回頂端）。
- 「複製條件連結」：`navigator.clipboard.writeText(location.href)`，成功時按鈕文字變「已複製」1.5 秒；失敗（非安全環境）時 `prompt('複製這個連結', location.href)`。

### 3-2 面額變更與減資的換算規則

1. 候選事件：匯出時算出的價格事件 `ev`（含上櫃反推的「調」）中，類型屬於 `CAP_TYPES`（權、權息、減、面、調），且 |參考價 ÷ 前收 − 1| ≥ 10%（和 `cap` 相同的門檻）。
2. 找事件日（含）之後該股第一個融資融券日 `d`，以及 `d` 之前該股的上一個融資融券日 `d'`。事件在該股第一筆融資融券之前 → 略過。
3. `k = d 的官方融資前日餘額 ÷ d' 的融資餘額`；`d'` 融資為 0 時改用融券（前日 ÷ 餘額）；兩者都是 0 → 略過（餘額 0 不需要換算）。
4. **|k − 1| ≥ `CONV_MIN`（0.1）才算官方有換算**，記成 `{"d": d, "k": round(k, 4), "t": 事件類型}`。除權（6669）官方不換算，k = 1，自然略過。
5. 某一天的餘額換算到最新單位 = 乘上「該天之後所有換算的 k」（`conv_k`）。
- **除權不換算**：股票股利要到發放日才入帳，信用交易餘額不會在除權日變動；規則 4 依官方資料判斷，不寫死類型。
- 11/04 全市場 16 次換算（附錄 A-3）：面額變更 2 次（k ≈ 10、20）、減資與上櫃「調」14 次（k 介於 0.49～3.95）。

```python
        last, prev = dates[-1], dates[-2]
        lots = lambda c, d: round(held[d][("ST", c)][1] / 1000) if ("ST", c) in held[d] else 0
        for c in {c for d in (last, prev) for (kind, c) in held[d] if kind == "ST" and c in tw}:
            out[c] += lots(c, last) - lots(c, prev)
    return {c: v for c, v in out.items() if v}


def trust_share(t, e):
    """B16：主動 ETF 占投信買賣超的 %（四捨五入整數）；同向且 |e| ≤ |t| 才有，其他（投信 0、反向、超過）→ None。"""
    return round(e / t * 100) if t and e and (t > 0) == (e > 0) and abs(e) <= abs(t) else None


def price_stats(d_, adj, tv, days, idx):
    """
    C3 價量欄位。d_：該股日線日期（舊到新，最後一列 = 資料日）；adj：還原收盤（無成交 None）；tv：成交額（元，None 當 0）；
    days：全市場交易日（舊到新，最後一天 = 資料日）；idx：{日期: 該市場指數收盤}。
    """
    yi = [float(x or 0) / YI for x in tv]
    px = [x for x in adj if x is not None]
    lc = px[-1] if px else None                          # 最後成交的還原收盤（今天無成交時是之前的收盤）
    traded = adj[-1] is not None
    out = {"a20": _f(sum(yi[-20:]) / 20) if len(yi) >= 20 else None}
    prior = yi[-21:-1]
    out["vr"] = _f(yi[-1] / (sum(prior) / 20)) if len(prior) == 20 and sum(prior) > 0 else None
    raw = {}
    for n in (5, 20, 60):
        b = days[-1 - n] if len(days) > n else None
        base = next((a for d, a in zip(reversed(d_), reversed(adj)) if d <= b and a is not None), None) \
            if b is not None and d_[0] <= b else None
        raw[n] = (lc / base - 1) * 100 if base and lc else None
        out[f"r{n}"] = _f(raw[n])
    for n in (20, 60):
        b = days[-1 - n] if len(days) > n else None
        ir = (float(idx[days[-1]]) / float(idx[b]) - 1) * 100 if b in idx and days[-1] in idx else None
        out[f"rs{n}"] = _f(raw[n] - ir) if raw[n] is not None and ir is not None else None
    for n in (20, 60):
        out[f"b{n}"] = _f((lc / (sum(px[-n:]) / n) - 1) * 100) if len(px) >= n else None
    out["nh"] = next((n for n in NH_DAYS if traded and len(px) > n and px[-1] > max(px[-n - 1:-1])), 0)
    out["nl"] = next((n for n in NH_DAYS if traded and len(px) > n and px[-1] < min(px[-n - 1:-1])), 0)
    return out


def revenue_stats(rows):
    """C3 營收欄位。rows：_revenue_rows 的輸出（舊到新）；取該股最新一個月。r3 = 最近 3 個月連續且年增都 > 0。"""
    if not rows:
        return dict.fromkeys(("rm", "ry", "rc", "rh", "r3"))
    y, m, _, _, yoy, cum, hi = rows[-1]
    l3 = rows[-3:]
    r3 = len(l3) == 3 and l3[0][0] * 12 + l3[0][1] + 2 == y * 12 + m and all(r[4] is not None and r[4] > 0 for r in l3)
    return {"rm": y * 100 + m, "ry": yoy, "rc": cum, "rh": hi, "r3": int(r3)}


def margin_conv(rows, ev):
    """
    融資融券的官方換算（面額變更、減資等）。rows：{日期: (融資前日, 融資餘額, 限額, 融券前日, 融券餘額, 註記)}（該股全部日期）；
    ev：_price_events 的事件。股本事件（CAP_TYPES、參考價變動 ≥ 10%）生效後第一個融資融券日 d：
    k = d 的融資前日餘額 ÷ 前一個融資融券日的融資餘額（融資為 0 改用融券）；|k − 1| ≥ CONV_MIN 才算換算。
    回傳 [{"d", "k"（4 位）, "t"}]（舊到新）；d 之前的餘額乘上 k 即與 d 之後同一單位。
    """
    ds, out = sorted(rows), []
    for e in ev:
        if e["t"] not in CAP_TYPES or abs(e["r"] / e["p"] - 1) < 0.1:
            continue
        j = next((i for i, d in enumerate(ds) if str(d) >= e["d"]), None)
        if not j:                                   # 找不到，或事件在第一筆融資融券之前
            continue
        cur, prev = rows[ds[j]], rows[ds[j - 1]]
        k = cur[0] / prev[1] if prev[1] else cur[3] / prev[4] if prev[4] else None
        if k is not None and abs(k - 1) >= CONV_MIN:
            out.append({"d": str(ds[j]), "k": round(k, 4), "t": e["t"]})
    return out


def conv_k(conv, day):
    """day 的餘額換算到最新單位要乘上的係數 = day 之後所有換算的 k 相乘。"""
    k = 1.0
    for c in conv:
        if c["d"] > str(day):
            k *= c["k"]
    return k


def screen_margin(rows, mdate, d5, conv, market):
    """C3／F8-3 的融資融券欄位（張、%）；5 日增減以換算後的 5 日前餘額計算。該市場沒有資料或該股不在清單 → 全部 None。"""
    r = stock_margin(rows, mdate, d5) if mdate else None
    if r is None:
        return dict.fromkeys(("mb", "m1", "m5", "sb", "s1", "s5", "sr", "mu", "mnt"))
    old = rows.get(d5) if d5 else None
    k = conv_k(conv, d5) if old else 1.0
    return {"mb": r["mb"], "m1": r["m1"], "m5": round(r["mb"] - old[1] * k) if old else None,
            "sb": r["sb"], "s1": r["s1"], "s5": round(r["sb"] - old[4] * k) if old else None,
            "sr": r["sr"], "mu": r["mu"], "mnt": (r.get("nt") or None) if market == "TWSE" else None}


def margin_series(d_, rows, conv):
    """個股 JSON 的 mg：與 prices.d 對齊的官方原始餘額（張），沒有資料的日期 null；k = 換算紀錄（沒有就不放）。該股沒有任何融資融券列 → None。"""
    if not rows:
        return None
    mg = {"mb": [rows[d][1] if d in rows else None for d in d_], "sb": [rows[d][4] if d in rows else None for d in d_]}
    if conv:
        mg["k"] = conv
    return mg


def screen_build(rows, head):
    """screen.json：欄式。rows：{代號: {SCREEN_KEYS…}}（依代號排序）；head：d、fd、md。rmd = 各營收月份的檔數。"""
    codes = sorted(rows)
    rmd = Counter(rows[c]["rm"] for c in codes if rows[c]["rm"] is not None)
    return {**head, "rmd": {str(k): v for k, v in sorted(rmd.items(), reverse=True)}, "codes": codes,
            **{k: [rows[c][k] for c in codes] for k in SCREEN_KEYS}}
```

### 接線（`export.py` 既有程式的修改點）

1. `_load_holdings`：SELECT 彙總列尾端加 `s.units`（彙總 tuple 變 7 欄）。
2. `holding_export`：`nav, nav_unit, n, w, fl, fa = summary[...][:6]`；回傳的 `sum` 加 `**({"u1": u} if (u := unit_change(...)) is not None else {})`。
3. `latest.json holdings[代號]`：`{d, n}` 之外同樣加 `u1`（None 不放）。
4. `_load_margin`：`per_stock` 的查詢拿掉 `WHERE x.trade_date >= mdates[0]`（讀完整歷史）；組 `stocks[m][d]`（市場彙總用）時仍只取 `d >= mdates[0]`，`market_margin` 輸出不變。
5. 個股迴圈：`ev` 算出後呼叫 `margin_conv(ev, rows)`；個股 JSON 加 `mg = margin_series(...)`（None 不放）與 `act`（1-3 節，None 不放）。注意迴圈內變數 `m` 會被重新指派為 `market[...]`，新程式不要沿用 `m` 當市場代號。
6. 快照完成後 `screen_build(...)`，在寫 `latest.json` **之前** `_write(out / "screen.json", ...)`，並印出 2-4 節的一行。
