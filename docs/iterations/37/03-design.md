## 二、匯出（F37-1）

### 2-1 `stocks/{代號}.json` 的 `band`

```json
"band": {"d": "2026-11-20",
         "pe": {"s": [["2025-11-20", 61.19], ["2026-02-26", 66.24], …, ["2026-11-13", 98.24]], "k": [24.02, 27.59, 28.76, 31.4, 32.8], "n": 242},
         "pb": {"s": [["2025-11-20", 192.7], …], "k": [7.76, 8.9, 9.7, 10.24, 10.63], "n": 242}}
```

| 鍵 | 意義 |
|---|---|
| `d` | 資料日 = `val_date`（窗口最後一天；和 `val.d` 相同） |
| `pe`／`pb` | 各指標一組；不輸出的指標整個鍵不存在 |
| `s` | 階梯：`[起日, 值]`，舊到新；值 = 原始收盤 ÷ 官方本益比（淨值比），**4 位有效數字**；`null` = 官方值空或 ≤ 0（虧損）。下一段起日前都用這一段的值 |
| `k` | 窗口內官方值（> 0）的第 10／25／50／75／90 百分位，由小到大；官方原值（2 位小數），不再四捨五入 |
| `n` | 窗口內官方值 > 0 的天數 |

- 位置：個股 JSON 的 `val` 之後（`**({"band": …} if stock_band.get(code) and not cap else {})`）。
- 只在 `stocks/`；`etfp/`、`latest.json`、`screen.json` 不變（`test_iter15:83`、`test_iter08:176` 照常通過）。

### 2-2 規則（常數寫在 `export.py`）

| 規則 | 定義 | 常數 |
|---|---|---|
| 窗口 | 和 `val` 完全相同：`stock_fundamentals` 最近 `VAL_DAYS` = 242 個交易日（目前 2025-11-20～2026-11-20） | `VAL_DAYS` |
| 反推 | 每天值 x = 原始收盤（`daily_prices.close_price`）÷ 官方值；只用當天公布的值，沒有前視 | — |
| 虧損 | 官方值空或 ≤ 0 → 若上一段不是 `null`，開一段 `[日期, null]` | — |
| 無成交 | 收盤空、官方值 > 0 → **沿用前一段，不切**；`null` 段之後第一個有收盤的日子才開新段 | — |
| 切段 | `|x ÷ 這一段已輸出的值 − 1| > max(0.5%, 0.012 ÷ 當天官方值)` 才開新段。比較對象是「已輸出（4 位有效數字）的段值」，不是前一天，所以窗口內每個有收盤、有官方值的日子，`收盤 ÷ 段值` 和官方值的相對差一定 ≤ 該日門檻（驗收 2 的定義） | `BAND_TOL = (0.005, 0.012)` |
| 有效數字 | 段值 `float(f"{x:.4g}")`（相對誤差 ≤ 0.05%）；不用 2 位小數（EPS 0.35 用 2 位小數誤差可達 1.4%，是分析師實測 91、103 段的主因） | — |
| 段數上限 | 段數 > 24 → 不輸出該指標（視為反推雜訊太大；目前 0 檔觸發） | `BAND_SEG_MAX = 24` |
| 天數不足 | `n` < `VAL_MIN`（120）→ 不輸出該指標；兩個都沒有 → `band_series` 回傳 `None`，不輸出 `band` | `VAL_MIN` |
| 百分位 | **最近序位法**：官方值由小到大排列 a[1..n]，第 P 百分位 = a[⌈P × n ÷ 100⌉]。意思是「這一年有 P% 的天數小於或等於這個倍數」，和一年位置（≤ 今天的天數比例）同一套說法；值一定是某一天的官方原值，所以 `val` 的一年最低 ≤ `k[0]`、`k[4]` ≤ 一年最高 | `BAND_PCT = (10, 25, 50, 75, 90)` |
| 股本變動 | 90 天內股本變動（`capchg`）→ 不輸出 `band`，和 `val` 同一個 `cap` 判斷式（D66-4 = B） | `CAP_DAYS` |

- 門檻的理由：官方值只有 2 位小數，真值在 v ± 0.005，所以單日反推誤差 ≤ 0.005 ÷ v；同一段的兩天最多相差約 0.01 ÷ v。0.012 ÷ v 留 20% 餘裕；本益比 ≥ 2.4 時由 0.5% 下限決定。
- 例：1101 淨值比 0.78，門檻 = 0.012 ÷ 0.78 = 1.54%；今天反推 31.22 元、段值 30.83 元（8/13 起），相差 1.25%，在門檻內（官方值 0.775～0.785 的兩端相差就有 1.28%）。

### 3-1 位置與結構

- 基本面分頁：數字列 → 一年位置說明（`val-note`）→ 獲利說明（`fin-note`）→ **河流圖卡** → 月營收／季報（`<section class="sec grid …">`）→ 股利與填息。

- 卡片：

```
本益比河流圖（近一年）                       [本益比｜淨值比]
11/19  收 102  近 4 季 EPS 5.10 元  本益比約 20.00 倍     ← 十字線讀數（預設最後一天）
┌────────────────────────────────────────┐
│ 5 條倍數線（藍，同色）＋收盤（文字色，粗）；不塗色          │  高 220px
└────────────────────────────────────────┘
- - 第 90 百分位 32.80 倍  ━ 第 75 百分位 31.40 倍  ▬ 第 50 …    ← 圖例在圖下方，由上到下 90→10，最後「收盤（原始價）」
11/20 收盤 2,000 元 = 近 4 季 EPS 98.23 元 × 20.36 倍（近一年最低）
（條件說明 0～3 行）
倍數是用近一年的資料算的，不代表股價會回到某條線  說明▾
```

- 線的樣式（`BAND_STY`）：10／90 虛線 1px、25／75 實線 1px、50 實線 2px，顏色 `--blue`；收盤 `--text` 2px。不用 area／baseline 系列，也沒有填色。
- 圖：Lightweight Charts 4.2.0，`handleScroll`／`handleScale` 關閉（同籌碼圖）、`rightPriceScale.minimumWidth: 76`、`entireTextOnly: true`、`fixLeftEdge`／`fixRightEdge`、`attributionLogo: false`（同 `buildChip`）。
- 日期軸：`prices.d` 中 `s[0][0]` ≤ 日期 ≤ `band.d` 的日子。第 i 天第 j 條線 = 當天的階梯值 × `k[j]`；階梯值 `null` → 該點空白（線斷開，不補值）。
- 收盤：**一律 `prices.c` 原始價**，不經過 `aggregate`／`adjFactors`，和 K 線「還原／原始」無關；無成交日空白。
- 十字線讀數：日期、收盤、`近 4 季 EPS`（或「每股淨值」）＝階梯值、`本益比約 X 倍`＝收盤 ÷ 階梯值（標「約」，因為階梯值是一段的代表值）。滑出圖外回到最後一天。
- 今天一行：`{fund.date} 收盤 {最後成交收盤} 元 = {近 4 季 EPS／每股淨值} {收盤 ÷ fund[k]} 元 × {fund[k]} 倍（位置）`。
  - 倍數用頁首官方 `fund.pe`／`fund.pb`，不重算。
  - 位置用 `val[k]`：`fund[k] ≤ 一年最低` →「近一年最低」、`≥ 一年最高` →「近一年最高」、其餘「近一年第 P 百分位」，P = `val[k][0]`，**和頁首「一年位置」同一個數字與同一套最低／最高判斷**。
  - 注意：今天一行的 EPS（收盤 ÷ 官方倍數，2330 為 98.23）和十字線讀數的階梯值（98.24）可能差在門檻內（觀察 1）。

### 3-4 說明（三件事，不新增 `noteHTML('…'` 字面）

- 短句（收合後可見，用變數 `short` 傳入）：「倍數是用近一年的資料算的，不代表股價會回到某條線」。
- 完整說明 `BAND_NOTE(k, n)`：
  1. 倍數線 = 當天的近 4 季 EPS（每股淨值）× 近一年官方本益比（淨值比）的百分位；EPS 由證交所、櫃買中心公布的本益比反推（原始收盤 ÷ 本益比），官方換用新財報時倍數線才會跳動（淨值比版：通常一季更新一次）。
  2. 百分位定義（最近序位、n 天）；收盤是原始價，和 K 線預設的還原價不同。
  3. 倍數是用這一年的資料算的，舊日期的線也用到之後的資料；股價約有一半時間在中間兩條線之間是計算方式造成的，不代表股價會回到某條線；只有一年資料，不是長期區間，也不能用來回測（Q37-6）。
  4. 河流圖只描述股價和近 4 季獲利（每股淨值）的關係，**不是股價的評價**，也不是投資建議；獲利大增時股價會落到低倍數線附近，例如景氣循環股在獲利高峰（只有本益比版）。
- 分析師 4-3 的「不代表合理價格」改寫為「不是股價的評價」，沒有靠掃描時剔除。
- `noteHTML` 字面呼叫仍是 8 個（`test_iter13:81`、`test_iter24:293`）。

## 七、觀察（不算缺陷）

1. **十字線讀數和今天一行的 EPS 可能差一點**：今天一行用「收盤 ÷ 官方本益比」（2330：98.23，和頁首倍數一致），十字線用階梯段值（98.24，11/13 那天反推）。差距 ≤ 切段門檻；十字線的倍數因此標「約」。若要完全一致，可改為今天一行也用段值，但那樣「收盤 = EPS × 倍數」會對不起來（98.24 × 20.36 = 2,000.2），所以維持現狀。
2. **分析師的 91、103 段消失了**：原因是段值改用 4 位有效數字，而且和「已輸出的段值」比較。全市場最多 7 段，所以 `BAND_SEG_MAX = 24` 目前不會觸發，只是保護。
3. **新上市股的起點**：`s[0][0]` 是第一個「有收盤且官方值 > 0」的日子（或第一個虧損日），所以前面無成交的日子不畫（5703：窗口第 1 天 11/20 無成交，從 11/24 起）。
4. **1436 本益比 3,080 倍**：EPS 只有 0.01 元，今天收盤遠在所有倍數線之上（今天位置第 95 百分位）；照狀態表「照畫」並顯示「間距很寬」說明。
5. 2881 淨值比在 2025-11-27 有一次 53.47 → 61.78 的跳動（+15%），是官方淨值比本身的變化（可能是官方換算基礎），照實呈現。
