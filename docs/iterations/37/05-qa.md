## 五、觀察（不算缺陷）

1. **切段 `>` 改 `>=` 擋不下**：只在「相對差剛好等於門檻」時不同；全市場最接近的是 2538（比值 0.99986），浮點數剛好相等幾乎不會發生，不補。
2. **今天無成交的 11 檔**（例 2235、8923、6997）：今天一行寫「11/20 收盤 28 元」，28 元其實是 11/19 的成交價。官方在無成交日沿用最後成交價計算倍數（2235：11/19、11/20 本益比都是 27.45），所以「收盤 = EPS × 倍數」仍成立；只是「11/20 收盤」用詞不精確。可在之後改成「最後成交」，本輪不改。
3. **十字線與今天一行的 EPS 差一點**（2330：98.24 vs 98.23），同設計觀察 1，差距 ≤ 切段門檻，十字線已標「約」。
4. **1303、3105 等倍數線很寬**：刻度被第 90 百分位撐開，收盤線擠在下方，是 D68 = A 的預期結果（1303 本益比沒有 > 100，不顯示「間距很寬」說明）。
5. 內建瀏覽器用 `dispatchEvent` 送的滑鼠事件不會觸發 LightweightCharts 十字線；十字線改用實際滑鼠移動驗證（01/22、08/31、滑出回到 11/20）。
