## 二、不做的項目與理由

| 項目 | 理由 |
|---|---|
| 分點買賣、主力進出、籌碼集中度、券商分點績效 | 官方「買賣日報」查詢有驗證碼，不可繞過；第三方整理的資料不能用 |
| 八大官股 | 「官股券商」是媒體與網站自己的分類，沒有官方資料 |
| 即時走勢、五檔、內外盤、預估量 | 本站是收盤後匯出的靜態網站，沒有後端；也沒有可以合法轉載的免費官方即時來源 |
| 新聞、影音、專欄、研究報告、法人目標價 | 媒體或券商內容，有著作權；不是官方資料 |
| 論壇討論、風向、問答、投票 | 社群內容，不是事實資料，也容易被讀成建議 |
| 被動 ETF、一般基金的持股 | 各投信各自公布、格式不一；投信投顧公會的月報不屬於本站限定的官方來源。主動 ETF 照舊只收已能穩定取得的 8 檔 |
| 產品營收組成 | 只在年報 PDF，沒有結構化來源 |
| 權證 | 範圍大、和本站定位無關 |
| 「可現股當沖」標記、追蹤人數 | 前者需另一份官方清單、價值低；後者是社群數字 |

### Q22-1「MACD 柱放大／縮小」在負柱時意思相反（高）

- 程式：`site/stock.js` 第 510 行 `chk(hist[i] > hist[i - 1], 'MACD 柱放大', 'MACD 柱縮小')`。
- 柱為負（DIF < DEA，圖上是橘色柱）時：
  - 柱值變大，代表**負柱縮短**，畫面卻寫「MACD 柱放大」。
  - 柱值變小，代表**負柱加長**，畫面卻寫「MACD 柱縮小」。
- 2421 這 5 天的柱值：−3.25 → −2.43 → −1.74 → −1.57 → −1.13。
  - 圖上的橘柱一天比一天短，訊號卻寫「MACD 柱放大」，而且算 1 項偏多。
- 11/13 全市場 1,987 檔中：
  - **1,231 檔**是「負柱縮短」，被寫成「柱放大」。
  - 用原始收盤估算；網站用還原價，數字會有小差異。
- 修正：
  - 多空歸類不用改（柱值上升算偏多）。
  - **只改用詞**，改成「MACD 正柱加長／正柱縮短／負柱縮短／負柱加長」，或「MACD 柱值上升／下降」。由 SA 決定。
  - 約 5 行，另加 1 個測試。
