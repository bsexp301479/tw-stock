## 三、缺陷

### D33-QA-1（中）週 K 的標籤蓋住別根 K 棒

**現象**

- 標籤有不透明的底色，放在 K 棒之上。如果標籤的範圍內有比較高的 K 棒，就會把那根的上影線或實體遮住。
- 例如 375 深色，6138 週 K：
  - 「7/31 息」蓋在最高的幾根 K 棒上，遮住了 400 以上的高點。
  - 截圖上看不到這一段行情的最高點。
- 例如 6465 週 K：
  - 「11/24 調」靠左緣往內收。
  - 往內收後蓋住了左邊幾根 K 棒的實體。

**量測方法**

- 讀 canvas 像素，計算每個可見標籤的範圍內有幾個漲色或跌色的像素（容許差 ±40，alpha ＞ 200）。
- 對照：同一張圖共有 16,142 個漲跌色像素，證明偵測方法有效。
- 樣本：
  - 2421。
  - 分析師統計的 5 檔相近事件。
  - 以 seed 33 從 1,527 檔有事件的股票中抽出的其餘樣本。
  - 共 39 檔，每檔測週 K、月 K。

**結果（375 深）**

| 畫面 | 標籤蓋到 K 棒的檔數 | 蓋到的像素數 |
|---|---|---|
| 週 K | **24／39**（其中 2421 只有 2 個像素，可忽略） | 34～760 |
| 月 K | 0／39 | — |

- 週 K 蓋到最多的幾檔：

  | 股票 | 標籤 | 像素數 |
  |---|---|---|
  | 6465 | 11/24 調 | 760 |
  | 6138 | 7/31 息 | 540 |
  | 3373 | 8/28 息 | 540 |
  | 4155 | 10/19 減・10/20 息 | 516 |
  | 6195 | 6/29 息 | 328 |
  | 6186 | 8/26 現增 | 288 |

- 1024 淺，用 8 檔重測週 K：
  - 3 檔仍然會蓋到：6465 104、4155 548、6195 102。
  - 寬螢幕一根 K 棒比較寬，問題比較少，但沒有消失。

**原因**

1. 垂直位置只參考「事件那根與左右各 2 根」的最高價（`H.slice(i - 2, i + 3)`）。
2. 375 寬的週 K，一根約 4～5.5 px。標籤寬 49～110 px，會橫跨 10～25 根。
3. 所以 ±2 根以外的 K 棒，如果比較高，就會被標籤蓋住。
4. 標籤靠左右緣往內收時，橫跨的 K 棒又會再往旁邊移，問題更明顯（例如 6465）。

**和改前比較**

- 改前：文字直接畫在 canvas 上，沒有底色。被上影線穿過時，**字讀不清楚**，但 K 棒還看得到。
- 改後：**字一定讀得清楚**，但標籤範圍內比較高的 K 棒會被遮住。
- 被遮住的常常就是一段行情的最高點，影響看圖。所以列為「中」。

**建議修法（給設計、PG 評估，QA 沒有改程式）**

- 方案 A（建議）：
  - 先決定標籤的水平位置。
  - 垂直位置改用「水平位置 ±2 px 範圍內所有 K 棒的最高價」，再往上。
  - 也就是把 `evLabelPos` 的輸入從單一個 `top`，改成能依標籤實際寬度查最高點。
  - 估計 `stock.js` 約 +5～8 行，`test_iter33` 要補案例。只改本輪新增的測試，舊測試不動。
- 方案 B：
  - 把 ±2 根改成依寬度換算的根數（`Math.ceil(w / 2 / barSpacing)`）。
  - 改動比較小，但往內收的標籤仍可能漏算。
- 方案 C：維持現況，在文件裡列為已知限制。
