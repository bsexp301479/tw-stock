## 三、觀察（不算缺陷）

1. **除息前收盤用官方值**：1259 除息前幾天沒有成交，最後成交收盤 58.0，但 `dv` 的除息前收盤是官方的 57.6。這是第 24 輪「股利與填息」卡的定義（`_price_events` 的 `p`），本輪照用；填息天數不受影響。
2. **距填息價可能很大**：6449 −71.88%、8261 −70.83%，查個股 JSON 是股價真的走低。
3. **權息的距填息價包含配股稀釋**：與設計觀察 2 相同，和個股頁定義一致。
4. 瀏覽器主控台的 `ERR_CONNECTION_REFUSED` 是 8001 停止期間分頁還開著留下的，和本輪程式無關；測試期間沒有 JavaScript 錯誤。
