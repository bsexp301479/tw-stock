### F35-1 匯出欄位

- 在 `SCREEN_KEYS` 後面加股利欄位，由 `dividends()` 已算好的 `dv` 推導，**不改 `dv` 的算法、不改個股 JSON**。
- 欄位意義（名稱、型別由 SA 定案）：
  - 最近一次「息」或「權息」的除息日（近 365 天內）。
  - 該次的除息前收盤。
  - 已填息時的填息天數（交易日，含除息當天）。
  - 中斷時的原因（和個股頁一致，例如「除權」「減資」）。
  - 近 365 天「息」「權息」次數。
- 排行要依除息日排序，而排行程式用 `isNum(x[field])` 篩選：SA 要決定匯出數字（例如「除息至今天數」），或在排行另寫排序。
- 「近 365 天」以資料日為準，寫成純函式，方便測試。
- 新欄位放在獨立函式（比照 `fin_screen`、`osc_stats`），`export()` 主流程只多一行。

### F35-2 選股條件（「基本面」組，放在殖利率之後）

| 條件 | 符合 |
|---|---|
| 近一年有現金配息 | 近 365 天「息／權息」次數 ≥ 1 |
| 最近一次已填息 | 有填息天數 |
| 最近一次尚未填息 | 有除息日、沒有填息天數、沒有中斷 |
| 近 {30／60／90} 天內除息 | 除息日在範圍內；預設 60 |

- 四個都顯示「最近除息／填息」欄；「尚未填息」另顯示「距填息價」。
- 中斷的股票不列入「已填息」「尚未填息」。

### F35-3 殖利率條件多一欄

- 勾「殖利率 ≥ N%」時，結果表多「最近除息／填息」欄。
- 「價值高息」組合（`pe=15&dy=5&tv=0.5`）條件不變，因為含殖利率條件，自然會多這一欄。
- 欄位內容：

| 狀態 | 顯示 |
|---|---|
| 已填息 | 除息日＋「N 天填息」 |
| 尚未填息 | 除息日＋「未填」＋距填息價 %（今天原始收盤 ÷ 除息前收盤 − 1） |
| 中斷 | 除息日＋「中斷（原因）」 |
| 近一年沒有 | `--` |

- 欄位可以點欄名排序（選股表既有功能），排序方式由 SA 定。

### F35-4 排行「近期除息」

- 放在排行「基本面」組，殖利率之後。
- 範圍：近 90 天內除息；依除息日由近到遠；同一天依成交額。
- 沿用排行的市場、成交額門檻篩選；最多 50 檔。
- 欄位：最近除息／填息、殖利率。
- 頁尾說明寫明填息定義、只看最近一次、股價資料起點。
- 網址 `#/rank/{代號}` 可分享（第 25 輪慣例）。
