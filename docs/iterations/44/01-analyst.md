### 4. QA40-04 `notices` 解析過濾 NaN／Infinity

- **目前狀況**：`twstock/collectors/notices.py:49`

  ```
          num = lambda k: clean_number(r[names[k]], Decimal)
  ```

  `clean_number("NaN", Decimal)` 回 `Decimal('NaN')`（`Infinity`、`-Infinity`、`sNaN` 同理）；`Decimal('NaN')` 為真值，`num(5) or Decimal(0)` 不會換成 0；寫入時 `format(v, "f")` 成 `NaN`，OPENJSON 轉 DECIMAL 失敗，整次收集回傳 2（同 QA40-01）。
- **建議修法**（1 行）：

  ```
          num = lambda k: x if (x := clean_number(r[names[k]], Decimal)) is None or x.is_finite() else None   # QA40-04：NaN、Infinity 當作沒有值
  ```

  非有限值當作「沒有值」：現金股利 → `None`（畫面「金額待公告」）、配股 → 0、認購率 → 0。只改 `notices`，不改共用的 `clean_number`（其他收集器也用，影響面大）。
- **實測**（副本）：上櫃一列現金 `NaN`、配股 `Infinity`、認購率 `-Infinity` → `cash_div None、stock_ratio 0、sub_ratio 0、sub_price None`。`test_iter40` 全部通過（沒有鎖這行的字面或雜湊）。
- **使用者可見文字**：無（官方正常資料不會出現）。
- **工作量**：程式 1 行；新測試約 6 行（上市、上櫃各一列 NaN／Infinity）。
- **資料庫／收集**：改的是收集時的解析，正常資料行為完全相同；不改表、不改請求數。改完後下一次排程就生效（Q44-2）。需 Python 3.8 以上（`:=`），本機 3.13。
