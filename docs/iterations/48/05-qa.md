## 五、程式審查（`git diff` 與 `compare.js`）

- **`export.py`**：`ix_export` 是純函式；`_f(None)` → None，`idx_close["TWSE"]` 只放非空值，缺日 → `null`。寫在個股與 ETF 迴圈之外，用既有 `_write`。
- **`ix.json` 不存在或讀取失敗**：`getJSON(...).catch(() => null)`；404、壞 JSON、網路錯誤都顯示「找不到交易日資料（data/ix.json），重新匯出資料後才能比較」，不快取失敗（恢復後再進就正常，實測）。chip 仍列出（沒有圖與表）。
- **某檔 JSON 404**：`Promise.all` 丟例外 → `route()` 的「載入失敗：data/stocks/2454.json 404」（PM 規格「沿用 route()」）；網址不正規化、`App.stockCache` 不會存失敗的檔。
- **只放 1 檔**：該檔＋加權指數 2 列，照常。**全部無效**：`#/compare`＋找不到提示＋空狀態。
- **資料不足**：`cmpBase` N 日不足 → null → 用 `ix.d[0]`；日報酬 < 20 → `--`；共同起點 = 終點（今天才上市）時 `n = 0`，報酬 0、跌幅 0、波動 `--`，不會除以 0 出錯。
- **共同起點晚於區間終點**：不會發生（第一個成交日 ≤ 最後一天 = 終點）。
- **無成交在尾端**：線持平、標「（無成交）」，表格名稱下方「最後成交 M/D」（00625K 實測）。
- **ETF 沒有 `epf`**：移除＋提示（暫時刪掉快取中 0056 的 `epf` 實測：`#/compare/0056,0050/w` → `#/compare/0050/w`＋`本站無法確認 0056 的價格調整，暫不比較`）。
- **`cmpEvents` 的 `gx` 日找不到列**：`indexOf` = −1 或 0 時 `p` 為 undefined，`r / p` 是 NaN，比較不成立而略過；匯出端保證 `gx` 在 `prices.d` 內，實際不會發生。
- **網址解碼**：見 QA48-01。另：目前 `cmp-msg` 直接把網址字串放進 `innerHTML`，因為 `location.hash` 的 `<`、`>`、`"` 都保持 `%3C` 等編碼所以不會成為 HTML（實測 `%3Cb%3E` 顯示為文字）；**若只加解碼而不加 `esc`，就會變成可插入 HTML**，所以修正一定要兩行一起改。
- **記憶體／事件監聽**：圖表放在 `stock.js` 的 `charts`，重畫時 `disposeKCharts()`、換頁時 `route()` 的 `disposeStockCharts()` 釋放；`input`／`keydown`／`blur`／`mousedown`／`click` 都掛在每次重畫會被換掉的元素上，沒有掛在 `document`／`window`，不累積；十字線訂閱隨圖表 `remove()` 一起釋放。離開比較頁後 `#cmpL` 不存在、比較圖 0 個、主控台沒有錯誤。

## 七、發現的問題

### QA48-01（低）網址含空白或 `%2C` 時沒有解碼，有效代號被移除、提示顯示 `%20`

- 重現（8001）：
  - `#/compare/2330, 0050 ,tsmc/xx` → `#/compare/2330/w`，提示「找不到 %200050%20、TSMC，已從比較清單移除」——**0050 被移除**。
  - `#/compare/2330%2C0050/w` → `#/compare`，提示「找不到 2330%2C0050…」。
- 原因：瀏覽器把網址列的空白編成 `%20`，`route()` 的 `location.hash.split('/')` 不解碼，`cmpNorm` 的 `trim()` 去不掉 `%20`。`test_norm` 直接傳字串，沒有經過瀏覽器編碼，所以沒抓到。
- 影響：只有手動在網址列打空白，或分享工具把逗號編成 `%2C` 時發生；網站自己產生的連結（入口、加入、移除、換區間）都沒有空白。嚴重度「低」。

### QA48-03（觀察）載入中切頁的競態

### QA48-04（觀察）`-0.00%`
