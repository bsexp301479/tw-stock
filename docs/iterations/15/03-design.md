## 一、F15-1 累計 EPS 年增基期、由盈轉虧

### 1-1 匯出：`fin.c.eb`

- 鍵：`stocks/{代號}.json` 的 `fin.c.eb`，數字（元，2 位，`_f`）。
- 值：最新一季 `(y, q)` 的**去年同期累計 EPS** = `quarterly_financials` 的 `(y − 1, q)` 的 `eps`。和 `c.ey` 用的基期（`fin_stock` 內的變數 `eb`）是同一個值。
- `null` 的情況：沒有去年同期的列、或該列 `eps` 為 NULL。**一律輸出鍵**（值可能是 null）；沒有任何季報的股票照舊沒有 `fin`。
- 由新函式 `fin_cum_base(cum)` 產生，在 `export_all` 組裝時合併：`{**fb, "c": {**fb["c"], "eb": fin_cum_base(fin[code])}}`。
  - 不改 `fin_stock` 的回傳值：`test_iter10` 用 `==` 比對 `f["c"] == {"e": 2.0, "ey": 100.0}`（同第 14 輪的做法，第十四節第 1 點）。
- `c.e`、`c.ey`、`c.fs`、`fin.q`、`e4`、`e4p` 的值都不變（compare 驗證）。

### 1-2 門檻與畫面

- 沿用第 14 輪的 `EPS_BASE = 0.1`、`epsLow(v, b)`，不另立門檻（使用者未表示偏好，依 PM 建議）。
- 個股「基本面」季報卡「累計 EPS」那一格的副標（`renderFin` 的 `cy`）：

  | 條件 | 顯示 |
  |---|---|
  | `ey` 有值、`eb` < 0.1（`ey` 有值代表 `eb` > 0） | `年增 基期低（去年同期 X 元）`，不顯示百分比；本期虧損（4768）也一樣，不加「轉虧」 |
  | `ey` 有值、`eb` ≥ 0.1 | 照舊 `年增 +12,666.7%` |
  | `ey` null、`eb` ≤ 0、`e` > 0 | `年增 轉盈`（和單季一致） |
  | 其他（`eb` null、本期也 ≤ 0、舊 JSON 沒有 `eb` 而 `ey` null） | `年增 --` |
  | 舊 JSON（沒有 `eb`）、`ey` 有值 | 照舊百分比 |

- 用字：單季是「去年同季」，累計是「**去年同期**」。
- 單季那一格、柱狀圖提示、選股欄都不變（`test_iter14` 鎖住的字串照舊）。

### 2-3 除息推測（匯出端 `etf_gaps`）

- **只用於上市 ETF**。條件（全部成立）：
  1. 前一個資料列有收盤（有成交）；
  2. 當天有收盤、官方漲跌有值；
  3. `|收盤 − 官方漲跌 − 前一日收盤| ≥ 0.005`（= 官方參考價 ≠ 前一日收盤）。
- 對照 PM 的「官方漲跌 = 0、收盤 ≠ 前收」：
  - 漲跌 = 0 時，條件 3 就是「收盤 ≠ 前收」。**不設百分比門檻**：00929（月配）、0050（1 月半年配，71.85 → 71.80）的除息跌幅都 < 0.5%，設門檻會漏掉真的除息日。
  - **另外排除「前一個資料列無成交」**（234 次，多為冷門 ETF 的 1 個升降單位，例如 00707R）：上市前一日無成交時，官方漲跌相對的參考價不是前一個成交收盤，無法推測。
  - **另外納入「漲跌不是 0、但參考價改變」**（4 次，都是分割：0052 2025-11-26 245.30 → 35.35、00631L、00685L、00715L）：K 線上這種跳空最大，不標反而誤導。
- 11/06 結果（SQL 獨立重算相同，第八節 ⑥）：**507 個日子、117 檔**；其中官方漲跌 0 的 503 個、分割類 4 個。PM 參照的「> 2%」202 次、94 檔是這 503 個的子集。
- 匯出：`gx` 陣列；官方漲跌 0 的那幾天 `prices.ch` 改為 null（「不比價」，和個股 `_changes` 的口徑一致）。分割類保留官方漲跌（相對新參考價，是正確值）。
- **上櫃 ETF**：不推測。櫃買的漲跌 = 收盤 − 前一日收盤（11/06 PM 查證 247 天全部成立），除息日的漲跌含除息跌幅，資料裡沒有任何可辨識的訊號。

① **去年同期累計 EPS**（任抽 5 檔；11/06：4416 0.02、4768 0.01、6902 0.02、2344 0.12、2330 29.31）：

```sql
WITH last AS (SELECT f.stock_id, MAX(f.fin_year * 10 + f.fin_quarter) yq FROM quarterly_financials f
              WHERE EXISTS (SELECT 1 FROM daily_prices p WHERE p.stock_id = f.stock_id) GROUP BY f.stock_id)
SELECT s.stock_code, l.yq, c.eps, b.eps FROM last l JOIN stocks s ON s.stock_id = l.stock_id
JOIN quarterly_financials c ON c.stock_id = l.stock_id AND c.fin_year = l.yq / 10 AND c.fin_quarter = l.yq % 10
LEFT JOIN quarterly_financials b ON b.stock_id = l.stock_id AND b.fin_year = l.yq / 10 - 1 AND b.fin_quarter = l.yq % 10
WHERE s.stock_code IN ('4416', '4768', '6902', '2344', '2330');
```

           FROM etf_daily x JOIN etfs e ON e.etf_id = x.etf_id)
SELECT etf_code, COUNT(*), SUM(CASE WHEN ch = 0 THEN 1 ELSE 0 END) FROM t
WHERE m = 'TWSE' AND c IS NOT NULL AND pc IS NOT NULL AND ch IS NOT NULL AND ABS(c - ch - pc) >= 0.005
