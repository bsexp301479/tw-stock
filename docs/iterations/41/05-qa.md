## 四、觀察（不算缺陷）

1. **超過 2^53 的金額**：例如 9,999,999.99 元 × 999,999,999,999 股時，未實現損益會顯示成 -58,499,999,941,441,496 元，末幾位不準。原因是 BigInt 轉成 Number 顯示。PM 只要求 2^53 以內逐分正確，這個例子遠超過，實際不會遇到；和第 39 輪觀察 1 同類。
2. **桌機的刪除鈕、新增鈕高 26px**：觸控尺寸 34px 是既有 D25-12 的規則，只套用在 ≤720px。本頁沿用這個規則，和其他分頁一致。
3. **320 寬的明細表**：股數到 9.9 億這類極端值時，明細表會在表內左右捲動（263／254），整頁不捲。一般股數不會發生。
4. 主控台只有 `ERR_CONNECTION_REFUSED`，是 8001 停止期間分頁留下的；測試期間沒有 JavaScript 錯誤。
